# 教师使用手册

> 适用对象:班主任、副班主任、任课老师。本手册按「第一次使用 → 每天常用 → 偶尔用到 → 常见问题」的顺序写;文中用「」标出的都是页面上实际的按钮、菜单或页签名称;个别引号里写的是控件给读屏软件用的完整名称,屏幕上可能只显示简写(如「开始日期」显示为「开始」)。示例里的「示例小学」「张老师」「三年二班」「王小一」等都是虚构数据。
>
> 本版手册不带截图,截图随正式版文档补充。

## 1. 第一次使用

### 1.1 登录

1. 用学校信息中心给你的**登录名**和**临时密码**,在电脑浏览器打开学校提供的网址,进入「班级工作台」登录页,填「登录名」「密码」,点「登录」。
2. 第一次登录会被带到「首次登录请设置新密码」页:输入旧密码(就是临时密码)、新密码并确认。新密码至少 8 位(学校可能要求更长),字母、数字、符号至少两类。
3. 如果学校开了密码有效期,到期后登录会看到「密码已过期,请设置新密码」,改完才能继续。
4. 如果你的账号开了两步验证(见 3.9 节),密码正确后还会出现「两步验证」页,输入验证器应用里的 6 位数字。

同一账号连续 5 次密码错误会锁定 15 分钟,提示「失败次数过多,请 15 分钟后再试」。

### 1.2 欢迎页:选你的形象

第一次进入教师端会弹出「你好,张老师」欢迎页:

- 在「女老师」「男老师」两张卡片里点一个,这个形象会站在教室场景的讲台上;以后可在头像菜单的「我的偏好」里再改。
- 下面三行是功能速览(教室、成绩与 AI、家长与通知)。
- 点「开始」进入教室。欢迎页只出现一次;关掉也算看过。

### 1.3 认识界面

顶栏从左到右:

| 位置 | 内容 |
|---|---|
| 班级 | 只带一个班时直接显示班名;带多个班时是「切换班级」下拉,按班名的自然顺序排(三年二班、三年三班、三年十班)。右侧灰字是年级、教室和「第几周」(按学校设的开学日期算) |
| 主导航 | 「教室」「成绩」「分析」「学生」「AI 助手」;班主任还有「班级公告」 |
| 铃铛 | 「通知」:学校和年级发给你的通知,实时到达,点开即标为已读;需要回执的通知可以在铃铛里直接回执 |
| 主题 | 「主题:跟随系统 / 浅色 / 深色」轮流切换 |
| 头像 | 「账号菜单」:「我的偏好」「修改密码」「账号安全」「关于」「退出登录」;同时有管理岗或家长身份的人还会看到「切换到管理端」「切换到家长端」。「关于」显示产品名「班级工作台」、「版本」「学校」和一句「数据只存在学校自己的服务器上」 |

窗口较窄(平板、手机)时主导航只显示图标,顺序与上表相同;手机、平板等触屏上,顶栏导航、档案抽屉页签、学生表格里的按钮和对话框的关闭按钮都会放大一些,电脑上不变。

### 1.4 你的身份决定你能做什么

每个班里你的身份由学校在「组织架构」里任命,教室顶栏的老师形象旁会写「班主任」「副班主任」或「任课老师」:

| 功能 | 班主任 | 副班主任 | 任课老师 |
|---|---|---|---|
| 看教室、看学生档案基本信息 | ✓ | ✓ | ✓(看不到家庭信息) |
| 记考勤、确认考勤、导出本月 | ✓ | ✓ | 只读 |
| 点评加减分 | ✓ | ✓ | ✓(记入自己任教的科目) |
| 排座、班级设置(桌椅排列)、编辑黑板 | ✓ | — | — |
| 成绩录入 | 全部科目,可导出 | — | 只录、只看本科目,不能导出 |
| 学生名单增删改、批量导入、导出名单 | ✓ | — | 只看名单 |
| 评语、家长账号、班级公告 | ✓ | — | — |
| AI 助手 | 全部模板 | 部分模板 | 部分模板(班主任专用模板显示为禁用) |

进入某页看到「你在本班没有这项权限」,说明这一项不在你的身份范围内;需要的话请联系班主任或学校管理员。

## 2. 每天常用:教室页

点顶栏「教室」。页面主体是自绘的教室场景(讲台上站着你的形象,座位上是本班学生),底部是操作台:左边是模式条,中间是当前模式的操作,右边是「看看教室」「全屏」「待办与点评」三个图标按钮。

### 2.1 五种模式

模式条上按权限显示「日常」「考勤」「点评」「成绩」「排座」五个页签。

#### 日常

- 鼠标悬停在学生上看悬停卡:学号、职务、今日考勤、本周积分。
- 点学生打开学生档案抽屉(见 2.3 节)。
- 操作台上直接有「随机点名」和「编辑黑板」(编辑黑板仅班主任)。
- 「随机点名」自动跳过今天请假、缺勤的同学,只在已排座的同学里抽;抽中后可点「回答得好 +1」直接加一分,也可再抽一次。今天全班都没人可抽时提示「今天没有可点名的同学」;只剩一个人能抽时,点名卡上会注明「今天只有这一位同学可点名」。
- 「编辑黑板」:左右两块黑板各写一段文字,可设倒计时(名称和日期要一起填),倒计时会显示在黑板上。
- 前墙上还有「本周之星」(本周点评积分靠前的同学)和「本月寿星」两块小板;由学校在「学校设置 → 功能开关」里统一开关,关掉「本周之星」后连牌子一起不显示,「本月寿星」位置不变。

#### 考勤(班主任、副班主任可写,任课老师只看)

- 点一个学生,每点一次换一档:**出勤 → 请假 → 缺勤 → 迟到 → 出勤**。
- 操作台上有「确认考勤」和「全部出勤」。「全部出勤」会清掉当天已记的异常,有记录时会先弹确认。
- 「确认考勤」后,校长在管理端的「今日关注」和「考勤报告」里才会统计这一天;没确认的班会出现在校长的「还没确认考勤的班级」里。
- 「考勤日期」默认是学校的「今天」,可以点日期选以前的日子补记;离开考勤模式后自动回到今天。
- 「更多操作」(⋯)里有「导出本月」,导出当月考勤 CSV。
- 教室左侧的小牌显示「今日出勤」:实到人数、请假、缺勤、迟到。

#### 点评

- 点一个学生,弹出点评面板:上面是「表现好」「需改进」两组理由,每条理由带分值;底部可自填「理由」和「分值」(-10 到 10)。理由列表在「我的偏好 → 点评理由」里维护。
- 本班能选的科目不止一个时,弹层里有「科目」:班主任、副班主任可「不指定」;只任课的老师必须选一个,默认是自己任教的第一科。只教一科的老师不用选,系统自动记入该科。
- 操作台上有「全班 +1」「积分榜」「导出点评」。「积分榜」显示各小组(按座位分组)的累计积分和学生排名。
- 每次点评后右下角会出现提示并带「撤销」按钮,8 秒内可撤销;过了时限可到学生档案「成长记录」页签里的「点评明细」撤销自己给的那条。
- 点评会在教室里飘出加减分的动画,投屏时也能点评。

#### 成绩(需要成绩查看权限)

- 操作台上「选择考试」后,每个座位按名次着色(前 20% 到后 20% 的「名次色阶」),右上角角标显示比上一场**有分数的**考试进步或退步了几名(跳过没录分的空考试),没成绩的同学变暗显示「无成绩」。班里还没有任何考试成绩时操作台显示「还没有考试成绩」。
- 「完整分析」跳到分析页;「去录入」跳到成绩页。
- 全屏投屏时不着色、不显示角标,避免把排名投到大屏上。

#### 排座(仅班主任)

- 点两个学生互换,或直接拖拽;点一个学生再点空位可以挪过去。
- 操作台上直接有「随机打乱」「男女同桌」「优带弱」(按最近一场考试名次首尾配对,需要已录成绩;没有成绩时按钮旁直接写「还没有考试成绩」)、「撤销」「桌椅排列」「保存座位」;「更多操作」里有「放弃修改」「固定座位 / 取消固定」「打印」。
- 固定座位的同学不参加随机打乱、男女同桌和优带弱。
- 没座位的同学在舞台下方的「待安排」托盘里,拖到空位即可。
- 两位老师同时改座位时,后保存的人会看到「座位表已被其他人修改」:可以「放弃修改」载入最新的座位表,也可以「继续编辑」。
- 有未保存的修改时切换模式、切换班级或退出登录都会先确认。

### 2.2 操作台右侧三个按钮

| 按钮 | 作用 |
|---|---|
| 「看看教室」 | 本班登记了摄像头、且学校开着监控时才出现。点开在舞台下方显示本班摄像头画面(默认收起),画面上有带你姓名和时间的水印;再点一次或点「收起」关闭。详见 3.8 节 |
| 「全屏」 | 全屏投屏模式:日常、点评模式下不把考勤标签投出去,成绩模式不着色;再点「退出全屏」 |
| 「待办与点评」 | 右侧抽屉,三块:「待办」(自己记的事项,可「添加一件要做的事」)、「最近考试」(平均分、及格率、优秀率与「历次平均得分率」曲线,点「查看分析」)、「最近点评」 |

### 2.3 学生档案抽屉

在教室(日常模式)点学生,或在「学生」页点姓名,右侧打开「学生档案」抽屉,顶部按身份显示页签:

| 页签 | 内容 | 谁能看 |
|---|---|---|
| 「概览」 | 职务(班主任可改)、累计积分、本月考勤、生日、总分得分率、学科画像、最近成长记录 | 能看本班的老师 |
| 「档案」 | 学生基本信息、家庭信息、联系人、学习情况等;班主任还有「我的笔记」,只有你自己能看到 | 任课老师看不到家庭信息;副班主任只看基本信息 |
| 「成绩」 | 历次考试总分与排名、排名变化 | 有成绩查看权限的老师 |
| 「成长记录」 | 成长记录(班主任、副班主任可添加,删别人写的需要班主任)、「点评明细」(前 40 条点评,可撤销自己给的) | 有成长记录权限的老师 |
| 「评语」 | 手写评语点「保存评语」,成功后提示「已保存评语」;每条评语可「给家长看」(往年评语的开关只有这个学生**现在**所在班的班主任能动,别人看到的是灰色并注明「只有孩子现在的班主任能改」);AI 生成的评语标「AI 生成」,学校开了「AI 内容需审核后下发」时默认不给家长看 | 仅班主任 |
| 「家长」 | 家长账号管理,见 3.5 节 | 仅当前班的班主任 |

## 3. 偶尔用到

### 3.1 成绩:建考试、录分、导入、导出

点顶栏「成绩」。

**新建考试**(班主任;任课老师只能建只含本科目的考试):点「新建考试」,填「考试名称」「日期」「考试类型」(如月考),在「科目与满分」里勾选科目并确认满分(1–1000 的整数)。班级里没有的科目可以用「添加科目」手填,或点「从学校目录补齐」把学校设置的科目一次加进来。

**录入分数**:

- 左侧「考试列表」选考试,右侧是成绩表格。直接点格子打字,回车或方向键移动;空格子表示未录,输入「缺考」(或「缺」「-」「—」「/」「x」「X」)表示缺考。中文输入法打出来的全角字符(如「Ｘ」「／」,以及全角数字和小数点)也认,不用切换输入法。
- 从 Excel 复制一块分数后在表格里粘贴,会按位置填入;超出满分或格式不对的格子不会保存并有提示。
- 点「按表头导入」:把带表头(第一行有「姓名」或「学号」,其余列是科目名)的表格从 Excel 粘贴进去,或「选择 CSV 文件」,系统按表头对应科目。预览会写「识别到 N 行,匹配 N 人;科目:……」。Excel 直接另存的 CSV 多半是 GBK 编码,系统会自动识别;个别浏览器不支持时会提示「文件不是 UTF-8 编码,这个浏览器不能按 GBK 读取,请在 Excel 里另存为 UTF-8 的 CSV 后再试」。导入出错时按格子报:「第 N 行(不含表头与空行)· 科目(姓名):原因」——行号不算表头、也不算空行,与「识别到 N 行」的数法一致。
- 表格自动保存,表头右侧显示「保存中…」「已保存」或「保存失败」+「重试」。

**导出**:班主任点「导出」得到本场考试的 CSV(含总分与排名)。导出会先等正在保存的分数写完;还有格子没保存成功时会提示「还有成绩没保存成功,请先重试保存再导出」。任课老师没有导出。

**年级联考**:带「年级联考」标记的考试由教导处建立,老师不能改名、改科目或删除,录分照常;删除有其他老师负责科目的考试会被拒绝。

### 3.2 分析页

点顶栏「分析」或成绩页的「看分析」。

- 顶部「考试」下拉选考试。刚建好、还没录分的考试不会被当作"最新",页面会提示「「X」这场考试还没有分数,先显示最近一场有分数的考试」。
- 「对比」下拉默认不用动:系统自动拿上一场有分数的考试来比(旁边灰字写「默认与上一场有分数的考试比」,中间没录分的空考试会被跳过);也可以手动选一场,或选「不对比」。
- 指标卡:「平均分」「最高分」「及格率」「优秀率」「标准差」(越小说明分数越集中),有对比时每张卡带升降。及格线和优秀线由学校在「学校设置」里统一设定(默认按满分的 60% 和 85%)。
- 「总分分数段」图按学校的及格 / 优秀比例分成「不及格段」「及格段」「优秀段」三种颜色(刚好跨过分数线的那一档算及格段);「各科平均得分率」图里的「及格」参考线也是学校设的及格线,不是固定 60%。
- 下方还有「各科明细」表(满分、平均分、得分率、最高、最低、及格率、优秀率、不及格人数、得分率变化)、「得分率趋势」、「成绩排名」表(名次、姓名、总分、进退)与「需要关注」面板:「进步之星」「退步 5 名及以上」「两科及以上不及格」(只有一科可见时不显示最后一组)。
- 两个 AI 快捷入口:「AI 写分析报告」「给退步同学家长写沟通消息」(后者仅班主任,要有两场考试可对比,且有退步 5 名及以上的同学,否则提示「这两场考试之间没有退步 5 名及以上的同学」)。
- 任课老师只看到本科目的指标和排名。

### 3.3 学生名单

点顶栏「学生」。

- 「添加学生」:姓名、性别、学号、生日、职务、座位(可「自动加座位」或「不排座」)、家庭结构、标签(最多 12 个,到上限时提示「最多选 12 个标签,先取消一个再选」)、联系人(姓名和电话至少填一项,漏填时提示「联系人姓名和电话至少填一项」并把光标落到出错那行)、学习情况等。学号重复会提示「这个学号已经有人用了」。
- 「批量导入」:从 Excel 复制粘贴,或「选择 CSV 文件」;第一行是表头,至少要有「姓名」列;对话框里可下载「学生名单模板.csv」。
- 「导出名单」:导出本班名单 CSV。
- 顶部可「搜索学生」(姓名 / 学号 / 标签)和「筛选」(男、女、班干部、重点关注、住校、本月生日、未排座)。
- 点姓名打开档案抽屉;名单每行「操作」列的「编辑」打开「编辑学生」表单,删除在表单底部的「删除学生」。

名单增删时教室座位会自动增减排;学生标签从学校的「学生标签池」里选,也可以「自定义标签」。

### 3.4 AI 助手

点顶栏「AI 助手」。所有 AI 调用都经学校服务器转发,学生姓名默认替换成编号后再发给 AI 服务商,回复里再换回真名;电话、证件号一律过滤。

**用模板**:首页按「教学备课」「班级管理」「家校沟通」「学生成长」四类列出模板(备课教案、课件大纲、分层作业、班会课方案、活动策划、工作总结 / 计划、家长群通知、家长沟通话术、家长会发言稿、期末评语(批量)、成绩分析报告、谈心谈话提纲、生日祝福、个人评语、退步同学家长沟通)。选一个,按表单填好,点「开始生成」;你没有权限的模板显示为禁用,某一类下一个能用的都没有时显示「这个分类下还没有可用的模板」。学生档案抽屉顶部也有「AI 写评语」「家长沟通」两个快捷按钮(班主任)。

**自由对话**:首页「要做什么」输入框直接说需求,如「帮我写一份期中考试后的家长会发言稿」;可「+ 学生档案」「+ 考试数据」把资料带进去。点「发送」。

**对话页**:

- 「继续追问…」输入框继续对话;生成中可「停止」;对最后一条回复可「重新生成」。
- 每条回复下方可复制,也有自己的「导出 Word」只导这一条;页面顶部的「导出 Word」导出整个对话。
- 评语类回复可「保存为评语」(进档案的评语页签)、「记到成长记录」。
- 「隐去学生姓名」开关:默认勾选;学校强制时固定勾选并标「学校要求」。

**批量评语**(班主任):选「期末评语(批量)」模板,勾选学生,点「开始生成」逐个生成;每条可单独「保存到档案」,也可「全部保存到档案」。

**复制提示词**:任何模板和对话都有「复制提示词」:把拼好的提示词(姓名已替换成编号,附「编号对照表」)复制出来,贴到你自己常用的 AI 工具里。学校没有配置 AI 服务时也能用这一项,页面会提示「学校还没有配置 AI 服务,请联系管理员;可以先复制提示词」。

### 3.5 给学生建家长账号

班主任打开学生档案 →「家长」页签:

1. 点「添加家长」,填「手机号」「称呼」「关系」(父亲 / 母亲 / 祖辈 / 其他)。
2. 建好后弹出一次性对话框:登录名就是手机号,临时密码只在这个对话框里显示一次,可「复制」。请当面或电话告诉家长,关闭后无法再次查看。
3. 如果这个手机号已经有家长账号(比如另一个孩子的家长),会直接绑到原账号,提示「该手机号已有账号,已绑定到这个孩子,家长用原来的密码登录」,不改原密码。
4. 每个孩子 1 位「主家长」+ 最多 3 位次要家长;对某位家长点「设为主家长」可以换。需要回执的通知由主家长回执;主家长可以在家长端修改家庭联系人。
5. 家长忘了密码:点「重置密码」,再次得到一次性临时密码。家长账号同时也是本校教职工账号时不能由班主任重置,提示「该账号也是教职工账号,请联系信息中心重置」。
6. 「解绑」后这位家长看不到该学生;如果这是他唯一的孩子,账号会被归档,已打开的页面立刻回到登录页。

家长在手机浏览器登录后能看到什么,见 [家长使用手册](家长.md)。

### 3.6 班级公告(发给本班家长)

班主任点顶栏「班级公告」(带多个班时按当前选中的班发;地址里的班不在你的班级列表时页面显示「这个班不在你的班级列表里」,点「← 返回教室」回去重新选班):

- 「写公告」:填「标题」「正文」;「回执」可选「不要回执」「已知晓」「单选」(2–5 个选项,可勾「允许留言」),可设「截止时间」。点「发送」。
- 收件人是本班在读学生的**主家长**;一位家长有两个孩子在本班范围内时只收到一条。
- 「我发出的」列表里每条显示「已读 x / y」「回执 x / y」;点「回执」打开「回执统计」:已回执 / 未回执 / 未读三组名单、选项统计,可「导出 CSV」;点「撤回」后家长看不到正文,撤回不可恢复。
- 家长不刷新页面也能收到。已截止、已撤回的通知家长不能再回执。

### 3.7 班级设置(桌椅排列)与我的偏好

**班级设置**(班主任,教室页「更多操作」→「班级设置」):「教室」名称(班级名称由学校统一管理)、「每张桌子」几人、「行列」按人数自动排或自己设定排数与每排桌数、「讲台两边」各几张单人桌、「学生坐哪儿」(保持现在的座位 / 按学号横着排 / 按学号一组一组竖着排)。右侧有座位预览,保存后座位按新桌椅排好;排座有未保存修改时不能打开。

**我的偏好**(头像菜单 →「我的偏好」):「老师形象」(女老师 / 男老师)、「教室」里的空闲小动画开关、「点评理由」列表(理由 1–20 字,分值 -10 到 10 且不为 0)。

### 3.8 看看教室(摄像头)

学校开通监控并在本班教室登记了摄像头后,教室页操作台右侧出现「看看教室」:

- 班主任任何时候都能看本班。任课老师只在课表上自己这节课的时间段(提前 5 分钟到下课)能看,下课后显示「本节课已结束,看不到了」。
- 画面上有水印(学校名、你的姓名、时间),可「全屏查看」。切换模式或班级时画面自动收起。
- 只能在校园网内观看;用 iPhone / iPad 的 Safari 打开会提示「请在电脑或安卓浏览器上观看」。
- 看到「摄像头连不上」「这路摄像头的视频编码浏览器不支持(多为 H.265)」「同时观看的摄像头太多,请稍后再试」这类提示时,请告诉信息中心,不是你的操作问题。

家长端没有任何监控入口。

### 3.9 账号安全:两步验证

学校在「学校设置」里允许后,头像菜单 →「账号安全」里会出现「两步验证」:

1. 点「开启」,用手机上的验证器应用(常见的手机验证器应用都可以)扫描二维码,或「复制密钥」手动添加。
2. 输入应用显示的 6 位「验证码」和「当前密码」确认,看到「已开启两步验证」。
3. 以后登录在密码之后多一步「两步验证」。手机时间不准会提示「验证码不正确或已过期,请检查手机时间」。
4. 「关闭两步验证」同样要输当前密码。手机丢了、没法输验证码:联系信息中心在管理端「账号」页为你「重置两步验证」,重置后只用密码登录。

学校没开放时这里显示「学校未开启两步验证」。

### 3.10 修改密码

头像菜单 →「修改密码」:填「旧密码」「新密码」「确认新密码」。改完后你当前这个页面不掉线,**其他已打开的浏览器页面会回到登录页**,这是正常的。

## 4. 常见问题

**登录后提示「没有可查看的班级」「请联系学校管理员为你分配班级」。**
你的账号还没有被任命到任何班。请学校在管理端「组织架构」里给你安排班主任、副班主任或任课老师。

**提示「你在本班没有这项权限」。**
这一项不属于你在这个班的身份(见 1.4 节)。带多个班时请先确认顶栏选的是哪个班。

**忘记密码。**
找信息中心在「账号」页「重置密码」,拿到一次性临时密码后登录改密码。

**登录提示「失败次数过多,请 15 分钟后再试」。**
连续 5 次密码错误会锁 15 分钟,等一等再试;两步验证的验证码连错也计入同一个计数。

**换了手机,两步验证的验证码没法输了。**
找信息中心在「账号」页为你「重置两步验证」,之后用密码登录,再到「账号安全」里重新开启。

**排座时提示「座位表已被其他人修改」。**
另一位老师刚保存过座位。「放弃修改」载入最新座位表再改,或「继续编辑」然后保存覆盖。

**考勤记了,校长那边说没看到。**
考勤要点「确认考勤」才算这一天完成;「今日关注」和「考勤报告」只统计确认过的日子。

**点评点错了。**
8 秒内点提示上的「撤销」;超时后到学生档案「成长记录」页签的「点评明细」里撤销自己给的那条。

**AI 助手提示「学校还没有配置 AI 服务」。**
学校尚未在管理端配置 AI 服务商。可以先用「复制提示词」把提示词贴到自己的 AI 工具里;需要开通请联系信息中心。

**「隐去学生姓名」关不掉。**
学校在 AI 配置里勾了「强制隐去学生姓名」,所有老师的提示词都会替换姓名,并标「学校要求」。

**家长说看不到评语 / 排名 / 某条点评。**
评语要在档案「评语」页签打开「给家长看」;排名由学校设置「家长可见排名」决定(关着时家长只看到「班级前 10%」「班级前 30%」这样的段位,不在前 30% 或班里不足 10 人就什么都不显示);负向点评由「家长收到负向点评」开关决定。

**家长收不到班级公告。**
公告只发给**主家长**,且学生要在读、绑定在用。到学生档案「家长」页签确认这位家长是「主家长」、状态不是「已停用」。

**改了密码以后别的电脑上登录态没了。**
这是安全设计:改密码、管理员重置密码后,其他已打开的页面会回到登录页;你当前操作的页面不受影响。

**「看看教室」按钮不见了。**
本班没有登记摄像头,或学校关闭了监控总开关;任课老师在课表时段之外也看不到画面。

**成绩页的「从学校目录补齐」是什么。**
学校在「学校设置 → 科目目录」里维护各学段的科目;已有班级的科目不会自动变,老师建考试时点这个按钮把目录里缺的科目一次加进班级。
