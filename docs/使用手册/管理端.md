# 管理端使用手册

> 适用对象:校长 / 副校长、教导主任、年级组长、信息中心。本手册按「第一次使用 → 每天常用 → 偶尔用到 → 常见问题」的顺序写;文中用「」标出的都是页面上实际的按钮、菜单或页签名称。服务器的安装、备份、升级等运维操作不在本手册里,见随离线包一起发的 [deploy/README.md](../../deploy/README.md)。示例里的「示例小学」「张老师」「三年二班」等都是虚构数据。

## 1. 第一次使用

### 1.1 登录与身份

管理端账号由安装时的初始管理员(信息中心)建立。用登录名和临时密码登录后,先按提示「首次登录请设置新密码」改密码。只有管理身份的账号登录后直接进入管理端;同时也是老师的人进入教师端,在头像「账号菜单」里「切换到管理端」。

四种管理身份能用的页面不同(在「组织架构 → 管理岗位」里任命):

| 身份 | 能用的页面 |
|---|---|
| 校长 / 副校长 | 全部:今日关注、全校看板、通知,「学校管理」(组织架构、作息与课表、账号、学校设置、学年升级、往年班级),「联考与报表」(年级联考、成绩汇总、考勤报告),「系统」(审计日志、AI 使用、AI 配置、登录日志、摄像头) |
| 教导主任 | 今日关注、全校看板、通知、组织架构、作息与课表、学年升级、往年班级、年级联考、成绩汇总、考勤报告、AI 使用;不管账号、学校设置,看不到审计日志、登录日志、摄像头 |
| 年级组长 | 只看本年级:今日关注、全校看板、年级联考、成绩汇总、考勤报告;给本年级老师发通知(没有「全校」) |
| 信息中心 | 组织架构、作息与课表、账号、学校设置、审计日志、AI 配置、登录日志、摄像头;看不到学生、成绩等业务数据 |

### 1.2 认识界面

顶栏:「今日关注」「全校看板」「通知」直接显示,其余收进「学校管理」「联考与报表」「系统」三个下拉;没有权限的页面不出现,一个组只剩一项时直接显示成链接。右侧是铃铛「通知」、主题切换和头像「账号菜单」(「修改密码」「账号安全」「切换到教师端 / 家长端」(有对应身份时)「退出登录」)。

窗口较窄时导航只显示图标;手机上是可横向滚动的图标条。

### 1.3 开学准备清单

有「组织架构」或「学校设置」权限的人(信息中心、校长、教导主任)进入「今日关注」时,页面顶部有「开学准备」清单,逐项显示现状和去办的链接,全部完成后折叠成一行「开学准备已完成」。年级组长看不到这块。按清单从上到下做一遍,学校就能开学使用:

| # | 清单项 | 怎么算完成 | 去哪里做 |
|---|---|---|---|
| 1 | 学校与学段 | 每个年级都明确设了「学段」(小学 / 初中 / 高中),不要留着「按年级名称自动判断」;科目目录按学段取,这一项设好后面才有意义 | 「组织架构」→「学校」卡填「学校名称」「学校地址」;「年级与班级」里每个年级「编辑年级」选「学段」 |
| 2 | 学年 | 有一个当前学年 | 「组织架构」→「学年」卡:「学年名称」「开学日期」「第二学期开学日期」「结束日期」。开学日期决定老师教室顶栏显示「第几周」 |
| 3 | 班级 | 当前学年至少有一个班 | 「组织架构」→「年级与班级」:先「新建年级」,选中年级后「新建班级」(「班级名称」「教室」) |
| 4 | 账号 | 除初始管理员外至少有一个教职工账号 | 「账号」→「新建账号」或「批量导入」(见 3.1 节) |
| 5 | 班主任 | 每个班都有在任班主任 | 「组织架构」→ 点班名进「班级信息」→「任课与班主任」:「添加班主任」;顺便加副班主任和任课老师(带「科目」) |
| 6 | 课表 | 至少一个班有课表;学校没开监控时这项自动算完成,显示「未启用监控,可跳过」 | 「作息与课表」(见 3.5 节) |
| 7 | 摄像头 | 至少登记一路摄像头;没开监控时同样跳过 | 「摄像头」(见 3.6 节) |
| 8 | AI 服务 | 已配置 AI 服务;没配时显示「不配置也能用,只是没有 AI 助手」 | 「AI 配置」(见 3.4 节) |

任命班主任后,老师登录教师端就能看到自己的班;老师没有被任命到任何班时会看到「没有可查看的班级,请联系学校管理员为你分配班级」。

### 1.4 学校设置里先定好的几件事

「学校管理 → 学校设置」(信息中心、校长)从上到下六张卡,开学前建议过一遍:

- **「学生标签池」**:老师在学生资料里从这里选标签,顺序就是显示顺序。改名可勾「同时修改已有学生」。
- **「及格线与优秀线」**:按各科满分的比例,老师端分析、AI 统计、成绩汇总一起生效。「及格线(%)」30–95,「优秀线(%)」40–100,优秀线要高于及格线;默认 60 和 85(满分 100 分时 60 分及格、85 分优秀)。改了之后所有新算出来的及格率、优秀率立刻按新比例。
- **「科目目录」**:按「学段」(小学 / 初中 / 高中)维护科目和满分(满分 1–1000 的整数,每学段最多 20 门,科目名不重复)。「只影响之后新建的班级和联考可选科目」:已有班级的科目不变,老师可在成绩页用「从学校目录补齐」加进来;年级联考只能选目录里的科目。三个学段一起保存。
- **「功能开关」**:教室的「本周之星」「本月寿星」「教师可见互相的点评频率」;家长端的「家长可见排名」「家长收到负向点评」「AI 内容需审核后下发」(家长端下次刷新即生效;最后一项只对之后 AI 生成的评语生效,老师打开「给家长看」后家长才看得到);监控的「监控模块总开关」(「家长可看监控」v1 不开放)。
- **「账号安全」**:「允许账号开启两步验证」「密码最短长度」(8 到 32 位,已有密码不受影响、下次修改时生效)「密码有效期」(不限期 / 90 天 / 180 天 / 365 天)。
- **「系统」**:版本、数据库迁移、数据库大小、上次备份,以及「导出诊断信息」(见 3.9 节)。

## 2. 每天常用

### 2.1 今日关注

校长、教导主任看全校,年级组长看本年级。顶部指标:「在读」「出勤率」「请假」「缺勤」「迟到」「考勤确认」(已确认考勤的班数 / 班级总数);有进行中的「年级联考」时显示各班「录分进度」;「我发出的通知」显示已读情况。下面三块:

- 「今日缺勤与请假」:名单,点学生打开档案抽屉(只读)。
- 「还没确认考勤的班级」:班主任还没点「确认考勤」的班;没有班主任的班标「暂无班主任」。
- 「本周点评」:各班净分、需要关注的同学、老师点评次数。

只有班主任点过「确认考勤」的班,当天才算进出勤统计。

### 2.2 全校看板

按「年级」页签看每个班的教室缩略图、出勤 / 缺勤和本周点评;整张卡片可点,进入单班只读页(看教室、悬停看学生、点开档案,没有任何写入口;标「考勤已确认」或「未确认考勤」)。

学校开着监控且登记了摄像头时,看板旁边有「监控」侧栏(窄屏折叠,显示「监控 · N 路」):按年级列各班摄像头和状态点(「在播」「空闲」「故障」),点一个班看画面;「自动切换」每 10 秒换到下一个有画面的班;「九宫格」弹层里「勾选要看的摄像头」最多 9 路同屏。画面带观看者姓名和时间的水印,只能在校园网内观看;iPhone / iPad 的 Safari 不支持,请用电脑或安卓浏览器。

### 2.3 通知

校长、教导主任、年级组长在「通知」页「写通知」:

1. 填「标题」「正文」。
2. 「对象类型」选「发给老师」或「发给家长」。老师可选「全校老师」「某个年级」「某个班」「指定的人」;家长可选「全校家长」「某个年级」「某个班」(没有「指定的人」)。年级组长没有「全校」。选「指定的人」时「搜索姓名或登录名」逐个「添加」;名单里有人已被冻结会提示「有 N 位已不能接收通知」并可一键去掉。
3. 「回执」:「不要回执」「已知晓」「单选」(2–5 个选项,可「允许留言」),可设「截止时间」。
4. 点「发送通知」。老师在顶栏铃铛里实时收到;家长在手机上「通知」页签收到。发给家长时收件人是范围内在读学生的主家长,一位家长两个孩子都在范围内只收一条。

「我发出的」列表:每条显示范围、「已读 x / y」「回执 x / y」,标「家长」的是发给家长的。点标题:要回执的打开「回执统计」(已回执 / 未回执 / 未读名单、选项统计,「导出 CSV」),不要回执的显示收件人与已读情况。「撤回」后收件人看不到通知内容,不可恢复。

## 3. 偶尔用到

### 3.1 账号

「学校管理 → 账号」(信息中心、校长)。列表可「搜索姓名或登录名」,按「身份」(班主任 / 副班主任 / 任课老师 / 校长 / 教导主任 / 年级组长 / 信息中心)和「状态」(在用 / 已冻结)筛选;每行显示最后登录时间(「从未登录」表示还没登录过)。

- 「新建账号」:「登录名」「姓名」「手机」「工号」「科目」(用顿号或斜杠分隔,如 语文、数学)。建好后弹出「临时密码」对话框,**只显示这一次**,请把登录名和临时密码交给本人;对方首次登录需要修改密码。
- 「批量导入」:「选择 CSV 文件」或「粘贴 CSV 内容」,表头为「登录名,姓名,工号,科目,手机」,可下载「账号导入模板.csv」;先预览逐行问题,单次最多 500 行,全部有效才会建立。
- 每行「编辑」改资料;「重置密码」得到新的一次性临时密码;「冻结」后对方立即退出登录、不能再登录,历史记录保留,「解冻」恢复。不能冻结自己的账号。
- 「重置两步验证」见 3.2 节。

账号只是"能登录";这个人在哪个班是什么身份、是不是管理岗,在「组织架构」里任命。学生家长的账号不在这里建,由班主任在教师端学生档案的「家长」页签建。

### 3.2 两步验证与重置

**开放两步验证**:「学校设置 → 账号安全」勾「允许账号开启两步验证」并保存。之后每个账号(老师、管理者、家长)可自行在头像菜单「账号安全」里「开启」:用验证器应用扫二维码,输 6 位验证码并再输一次当前密码。开启后登录多一步「两步验证」。

**有人换了手机、验证码没法输**:没有恢复码,只能重置。有「账号」权限的人(信息中心、校长)在「账号」页找到该账号,点「重置两步验证」→「确认重置」。重置后该账号下次登录只要密码,之后本人可以重新开启。不能重置自己的两步验证;请至少保证学校有两个能进「账号」页的人。重置会写进审计日志。

关掉学校开关不影响已开启的账号:他们仍要输验证码,也仍可自行关闭。

### 3.3 登录日志与审计日志

**「系统 → 登录日志」**(信息中心、校长):每次登录尝试一条,列「时间」「登录名」「账号」「结果」「IP」「浏览器」「可疑原因」。可按「开始日期」「结束日期」「搜索登录名或姓名」「结果」(成功 / 密码错误 / 账号不存在 / 账号已停用 / 已锁定 / 验证码错误)筛选,勾「只看可疑」只看被标记的记录(「凌晨登录」:学校时区 0–5 点;「新网络」:该账号 90 天内没用过的网段)。可疑登录会给本人和信息中心各发一条「账号安全提醒」通知。「导出 CSV」导出当前筛选结果(导出本身也记入审计)。

**「系统 → 审计日志」**(信息中心、校长):谁在什么时候做了什么:「时间」「操作人」「操作」「对象」「结果」(成功 / 被拒),可按日期、「搜索操作人」、「分组」筛选,点「展开」看详情。只读,不能导出或删除。

### 3.4 AI 配置与 AI 使用

**「系统 → AI 配置」**(信息中心、校长):「服务商」「模型」「接口地址」「温度」(0 到 2)、API Key(「已配置,留空则不修改」;更换服务商或服务地址后需重新填写 API Key),「强制隐去学生姓名」勾选后老师在 AI 助手里不能关掉「隐去学生姓名」。填好先「测试连接」再「保存」。「清除」会让全校老师都用不了 AI 助手。API Key 加密后存在学校自己的服务器里,页面不回显。

**「系统 → AI 使用」**(校长、教导主任):按月看每位老师的「调用次数」「失败」「输入 token」「输出 token」「常用场景」,「上一月 / 下一月」切换。

### 3.5 作息与课表

「学校管理 → 作息与课表」(信息中心、校长、教导主任)。课表决定任课老师能在哪个时间段「看看教室」;班主任看本班不需要课表。没有开监控的学校可以不排。

1. **「作息时间」**卡:「添加节次」,每节填编号、开始时间、结束时间,「保存作息」。被课表用到的节次不能删除。
2. **「课表」**卡:选「班级」,点格子(周一到周日 × 节次)选「科目」和「老师」(「自动匹配」会按该班该科的任课老师填;留空显示「未指定老师」),「保存」;「清空」清掉这一格。
3. **「导入 CSV」**:表头「班级,星期,节次,科目,工号」,可下载「课表导入模板.csv」;星期写 1–7、周一或星期一都行;工号留空就按组织架构自动匹配老师。

### 3.6 摄像头

「系统 → 摄像头」(信息中心、校长)。摄像头的硬件要求、网络拓扑、服务器资源预算和运维故障排查,见 [deploy/README.md](../../deploy/README.md) 第 12 节「监控与摄像头」;这里只写页面操作。

**上线顺序**

1. 「学校设置 → 功能开关」打开「监控模块总开关」。关着时「摄像头」页提示「学校设置里的"监控"开关是关的,老师和校领导看不到画面」,不能新建。
2. 「摄像头」页「新建摄像头」:「名称」(如 三年二班教室)、「位置」(教室 / 走廊 / 操场 / 食堂 / 其他)、「班级」或「公共区域(不绑班级)」、「RTSP 地址」、「登录凭据(摄像头不需要就留空)」里分别填「用户名」「密码」(加密保存,不回显;编辑时「留空表示不修改」,「清除凭据」删掉已存的)、「转码(摄像头不是 H.264 时勾选,更占 CPU)」。
3. 保存后在列表里点「测试连接」。
4. 需要任课老师按课时看画面的,再到「作息与课表」录课表。

**地址怎么填**

- 必须是校园内网地址(`10.x`、`172.16–31.x`、`192.168.x`),用户名密码**不要**写进地址里,分开填。公网地址保存时会被拒绝。
- 登记**子码流**,不要登记主码流。常见写法:海康 `rtsp://<摄像头IP>:554/Streaming/Channels/102`,大华 `rtsp://<摄像头IP>:554/cam/realmonitor?channel=1&subtype=1`。子码流一般是 H.264、分辨率和码率都小,浏览器能直接播、不占转码 CPU。
- 在摄像头后台关闭「H.264+ / H.265+ / Smart Codec」这类智能编码,关键帧间隔设为 2 秒左右,首帧出得快。

**「测试连接」怎么看结果**

- 对话框会显示「正在连接摄像头,最多等 10 秒…」,成功后给一张预览图和一行流信息,如「编码 H.264 · 1920×1080 · 25 fps」。编码是 H.264 就可以直接用。
- 编码不是 H.264(多数是 HEVC,即 H.265)时会提示「测试成功,但浏览器放不出这路画面」和「这路视频不是 H.264,浏览器放不出来;请在摄像头里改成 H.264,或编辑这路摄像头勾选"转码"」。首选把地址改成 H.264 子码流;实在改不了再勾「转码」(每路约占一个 CPU 核,服务器配置低时只给少数几路用)。
- 「测试失败,请重试」:检查地址、端口、用户名密码、摄像头是否允许 RTSP over TCP,以及服务器到摄像头的网络是否通;可请运维按 deploy/README.md 第 12 节排查。

**列表与状态**

- 每行有「启用」开关,停用后老师和校领导看不到这一路;「编辑」「删除」。
- 状态「空闲」「直播中」「异常」;「异常」时状态下方的红字是最后一次连接的错误(地址里的口令已打码)。
- 页顶红色告警「以下摄像头地址不在校园内网,已拒绝拉流」:这些地址解析到了公网,改地址保存即可。

**谁能看**:班主任在教室页「看看教室」随时看本班;任课老师只在课表上自己这节课的时间段(提前 5 分钟到下课)看;校长、教导主任、年级组长在全校看板旁看;家长端没有入口。

### 3.7 组织架构的日常维护

「学校管理 → 组织架构」(信息中心、校长、教导主任):

- 「学校」卡、「学年」卡见 1.3 节。
- 「年级与班级」:年级可上移 / 下移、「编辑年级」「删除年级」;选中年级后右侧列班级(「班名」「教室」「班主任」「学生数」),「新建班级」「删除班级」。点班名进「班级信息」。
- 「班级信息」页:「基本信息」(班级名称、教室)、「任课与班主任」(「添加班主任」/「更换班主任」,换班主任时旧的立刻卸任;副班主任、任课老师带「科目」,「确认卸任」撤掉)、「桌椅排列」(只读摘要,具体由班主任在教师端「班级设置」里改)。
- 「管理岗位」:「校长 / 副校长」「教导主任」「年级组长」(选「负责年级」,一个年级可多位)「信息中心」。加减校长 / 信息中心岗位还需要「账号」权限。

### 3.8 联考、报表与学年

- **「年级联考」**(校长、教导主任、年级组长):选「年级」,「新建联考」填「考试名称」「日期」「考试类型」「科目与满分」(只能选科目目录里该学段的科目;已不在目录里的旧科目会标「已不在目录」);各班自动生成同名班级考试,老师在教师端录分。「各班录分进度」显示每班进度;联考后新建的班可「补建」。联考关联的班级考试老师不能改名、改科目或删除。「查看汇总」跳到成绩汇总。
- **「成绩汇总」**:「选择联考」,看各班「平均分」「及格率」「优秀率」对比(按学校设置的及格线、优秀线),点班级看学生成绩与班级 / 年级名次,「导出 CSV」。
- **「考勤报告」**:「月度考勤报告」按月看各班应到、出勤、请假、缺勤、迟到和出勤率,「只统计班主任确认过考勤的日子;迟到算出勤」;可按「年级」筛,点班级看学生明细,「导出 CSV」「打印」。
- **「学年升级」**(校长、教导主任):向导六步「新学年」→「班级去向」→「学生例外」→「新建班级」→「人员」→「预览」。
  1. 「新学年」:填「学年名称」(如 2027-2028学年)「开学日期」「结束日期」,点「生成建议」按现有班级自动生成方案(升一级、毕业班毕业)。
  2. 「班级去向」:每个班「升级」(新年级名、新班名、班主任)或「毕业」。
  3. 「学生例外」:选班级,把个别学生标「留级」(选目标班)或「离校」。
  4. 「新建班级」:新学年要新增的班(年级名、班名、班主任、每桌人数、行数、列数、座位方式)。
  5. 「人员」:逐个年级指定「年级组长」(可多位);不改时沿用原年级组长。
  6. 「预览」:逐班逐人看去向(随班 / 留级转入 / 留级转出 / 离校 / 毕业),点「执行升级」→「确认执行」。执行后新学年立即生效。
  
  草稿会自动保存,「重新生成建议」会覆盖草稿,「放弃草稿」清除。页面上方「最近一次升级」卡可「回滚学年升级」:只能回滚最近一次,新学年里已经有手动新建的年级、班级、任职、管理岗或新数据时会拒绝并列出数量。升级会把摄像头改绑到新班、复制课表到新学年。
- **「往年班级」**(校长、教导主任):选「学年」,只读查看往年班级的名单、考试与成绩。

### 3.9 诊断包

遇到问题需要技术支持时,「学校设置 → 系统」卡点「导出诊断信息」,得到一个 zip:版本、打码后的配置、数据库结构、各表行数、最近 3 天应用日志。「诊断包不含学生、成绩等业务数据,可以发给技术支持」,也不含服务器的 `.env` 配置文件。

诊断包对密钥、密码、令牌、手机号做了打码,但只覆盖已知模式;**发给校外之前请自己打开看一遍**,应用日志里的异常信息仍可能带业务内容。服务器端还有一份主机诊断脚本,见 deploy/README.md 第 10 节。

「系统」卡同时显示「版本」「数据库迁移」「数据库大小」「上次备份」;「上次备份」长时间不更新(正常是每天一次)请联系运维检查备份任务。

## 4. 常见问题

**年级组长说导航里没有某个页面。**
年级组长只有今日关注、全校看板、联考与报表和通知,且只看本年级;「往年班级」能进但看不到内容。需要更多权限要在「管理岗位」里换身份。

**老师登录后说「没有可查看的班级」。**
账号建好了但还没任命。到「组织架构」→ 点班名 →「任课与班主任」里把他加为班主任、副班主任或任课老师。

**新老师登录提示要改密码 / 临时密码忘了。**
首次登录必须改密码,属正常。临时密码只显示一次,忘了就在「账号」页「重置密码」再发一次。

**冻结账号后对方还在线?**
冻结后对方的下一次操作就会被登出,已打开的实时连接也会断开。

**老师反映「隐去学生姓名」关不掉。**
「AI 配置」里勾了「强制隐去学生姓名」,这是学校策略,不是故障。

**老师说 AI 助手提示「学校还没有配置 AI 服务」。**
到「AI 配置」填服务商与 Key,「测试连接」通过后「保存」。

**所有人都看不了摄像头,播放器显示「只能在校园网内观看」。**
多半是服务器的 `WS_TRUSTED_PROXIES` 配置与网络不匹配,伴随「登录日志」里的 IP 变成 `172.30.0.x`。请运维按 deploy/README.md 第 12 节「内网拓扑」核对。

**「摄像头」页不能新建。**
「学校设置 → 功能开关」的「监控模块总开关」没打开。

**老师说「本节课已结束,看不到了」。**
不是故障:任课老师只在课表时段内能看。核对「作息与课表」里这个班这一节的科目和老师。

**「测试连接」成功但老师播放时提示编码不支持。**
摄像头输出的是 H.265。改登记 H.264 子码流,或编辑这路摄像头勾「转码」。

**改了及格线,以前的报表数字变了。**
及格率、优秀率都是按当前学校设置实时算的,不保存历史口径;需要留档请在改之前「导出 CSV」。

**改了科目目录,老师的班级科目没变。**
目录只影响之后新建的班级和联考。已有班级由老师在成绩页「从学校目录补齐」。

**学年升级回滚被拒绝。**
新学年里已经有了手动新建的年级、班级、任职、管理岗或新的考试、点评等数据。回滚只在升级后尚未开始使用新学年时可做;确有需要请先清理列出的那些数据。

**诊断包能直接发给校外吗?**
先自己解压看一遍日志,确认没有不该外发的信息再发;诊断包不含 `.env`、密钥和业务数据表。

**想看服务器备份、升级怎么做。**
见 [deploy/README.md](../../deploy/README.md):第 7 节备份、第 8 节恢复、第 9 节升级与降级、第 13 节常见故障。
