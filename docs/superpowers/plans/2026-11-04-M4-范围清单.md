# M4 家长角色 · 范围清单

> M4 的目标:**家长用手机浏览器看自己的孩子**。本文件逐项写清 M4 做什么、不做什么、归 M4a 还是 M4b,以及用户 2026-11-04 拍板的取舍。
> 实施计划:[M4a 家长账号与看孩子](2026-11-04-M4a-家长账号与看孩子.md)、[M4b 通知到家长与回执](2026-11-04-M4b-通知到家长与回执.md)。
> spec:[`2026-11-01-三角色协作平台-design.md`](../specs/2026-11-01-三角色协作平台-design.md) §2.1–§2.6 / §3.2 / §4.4;D01–D17 一律不改。

## 为什么拆成 M4a / M4b

- 家长端要先有"家长从哪来、能看哪个孩子",通知才有收件人。按这个依赖切成两个能单独演示、单独打标的子里程碑:
  - **M4a 家长账号与看孩子**:班主任建家长账号、家长语境与手机端壳、今日 / 成长 / 成绩 / 档案、`ClassroomMap mode="mini"`、评语给家长看的开关、毕业后只读与归档,以及 L12(前半)、L32、L50。
  - **M4b 通知到家长与回执**:通知对象加"家长"、班主任给本班家长发班级公告、结构化回执与统计导出,以及 L44、L46、L47(通知部分)、L49。
- M4b 计划写于 M4a 之前,**M4b 开工前由 M4b 协调会话对照 M4a 合并后的 main 复核一遍**(接口名、文件路径、迁移号以代码为准,偏差写进第一个 PR)。

| 子里程碑 | tag | 验收(可演示) |
|---|---|---|
| **M4a** | `v0.6.0-m4a-parent-view` | 班主任(`teacher01`)在王小一的档案里给他建一个家长账号,拿到一次性临时密码;家长用手机号和临时密码在 375 宽的手机浏览器里登录,先改密码,再看到"今日"(出勤、今日点评、迷你教室里自己孩子的座位高亮、别人的座位没有姓名)、"成长"(成长记录、评语、点评历史)、"成绩"(每场考试的分数、班级平均、段位);同一个家长切换到另一个孩子;学校开关"家长可见排名"打开后段位变成名次。走完一次学年升级让一个班毕业,该班家长变成"只读历史"。E2E 全绿 + 浅 / 深 × 375 / 390 / 768 / 1280 走查 |

## 用户拍板(2026-11-04)

1. **家长账号发放**:**班主任直接建家长账号**(不做邀请码)。班主任在学生档案里填家长手机号与称呼,系统建账号(登录名 = 手机号)并生成临时密码,只显示一次,由班主任当面或电话告知;家长首次登录必须改密码(沿用 M3a 的 `must_change_password`)。手机号已经有账号的(如老师本人也是家长),直接把这个孩子绑到原账号上,不另建账号。不接短信。路线图里"邀请码绑定"由此改为"班主任建账号"。
2. **多对多与主 / 次家长**:一个家长账号可以绑多个孩子(家长端顶部切换孩子);一个孩子最多 4 位家长:**1 位主家长 + 最多 3 位次要家长**。第一位是主家长,班主任可以调换主次、解绑。按 spec:**主家长收通知、回执、可以改孩子的家庭联系人;次要家长只读、不收通知**。
3. **毕业 / 转出 / 移出之后**:孩子没有在读注册时,他的家长绑定转为**只读历史**:还能登录看孩子在校期间的成绩与成长,不再收通知、不能回执、不能改联系人;**满 365 天自动归档**:绑定结束,账号若已没有任何其他在用身份就改为 `archived`(保留数据,不能登录)。**v1 不删除**。学年升级回滚时恢复。
4. **家长能看什么**:**按 spec §2.3 矩阵全给**:孩子的基本信息、家庭信息、学习情况、性格特长 / 健康、全部标签都能读;成长记录全部类型都能看。班主任个人笔记始终不给家长。学校开关照常生效:"家长可见排名"关 = 只显示段位(前 10% / 前 30%)、开 = 具体班级名次;"家长收到负向点评"关 = 扣分点评不给家长看;"AI 内容需审核后下发"开 = AI 生成的评语要班主任点"给家长看"才可见。迷你教室**只标出自己孩子的座位,其他座位不显示姓名**。
5. **结构化回执**:发通知时选一种:**不要回执 / 只点"已知晓" / 单选**(2–5 个选项,单选时可勾"允许留言",≤ 200 字);截止时间可选,截止前可以改回执。发送人看回执统计(各选项人数、未回名单),给家长发的按学生汇总,可以导出 CSV。老师收到的通知也可以要求回执。
6. **谁能给家长发通知**:**班主任**在教师端给本班家长发(班级公告);**有发通知权限的管理者**(校长、教导主任,年级组长限本年级)在管理端可以选"全校家长 / 某年级家长 / 某班家长"。收件人是在读学生的主家长。
7. **成长记录附件(L21)**:**v1 不做**,v2 按客户需求再做(孩子照片属于敏感个人信息,还牵涉文件存储、备份、下载审计)。台账 L21 关闭为"放弃(v1)"。
8. **拆分**:拆成 **M4a / M4b** 两段,tag `v0.6.0-m4a-parent-view`、`v0.6.1-m4b-parent-notify`,各自合并后由协调会话打,需用户批准。

## 计划自定项(请审阅时留意)

1. **登录名 = 手机号**:家长账号的 `login_name` 与 `phone` 都是手机号。手机号唯一性靠 M3a 的 `(school_id, lower(login_name))` 唯一索引。
2. **"手机号已有账号"的判定**:本校 `active` 账号里登录名等于该手机号,或 `users.phone` 等于该手机号,就绑到它;不止一个时 409 `PHONE_AMBIGUOUS`,提示联系信息中心。为了不向班主任泄露同事信息,接口不返回对方姓名。
3. **三处一起写**:家长绑定同时写 `parents`(没有就建)、`parent_links`、`role_bindings`(`primary_parent` / `secondary_parent`,`scope = {student_id}`,`academic_year_id = NULL`),一个事务里完成;调主次时三处一起改。与 M3a"任职一处写三张表"同一做法。
4. **只读历史存在 `parent_links` 上**:`status ∈ {active, readonly, ended}` + `readonly_since` + `ended_at`;`role_bindings` 在归档(`ended`)时才写 `ended_at`。读接口按 `readonly_since + 365 天` 判定是否已过期,不等命令行。
5. **主家长唯一**:已有的部分唯一索引 `parent_links_one_primary` 改为只约束未结束的绑定(`WHERE is_primary AND status <> 'ended'`);每孩 4 位上限在服务里先锁学生行再数。
6. **家长端不复用教师端接口**:单独的 `/parent/*` 读接口,在服务层复用已有的取数函数(`build_profile`、`day_view`、`list_reviews`、`exam_table` 等),避免教师端接口为了家长再加分支。
7. **迷你教室不下发别人的身份**:接口只返回布局(行列、桌型、讲台边座位)、所有被占座位的坐标,以及自己孩子的座位;不返回其他学生的姓名、id、注册 id。
8. **段位口径**:按 M2b 班级名次(同分同名次),参考人数 n = 有总分的人数;名次 ≤ ⌈n × 10%⌉ 为"前 10%",≤ ⌈n × 30%⌉ 为"前 30%",其他不显示;n < 10 时不显示段位(人太少,段位等于名次)。
9. **L50 契约变更**:`POST /admin/years/upgrade/rollback` 请求体改为 `{upgrade_id}`,不是最近一次未回滚的升级 → 409 `UPGRADE_NOT_LATEST`;前端向导传"最近一次升级"卡片上的 id;命令行 `year-upgrade rollback` 增加可选 `--upgrade-id`,不传时行为不变。
10. **回执按学生汇总**:给家长的通知,发送那一刻就把"学生 → 主家长"写进 `notice_students`;统计按学生行算,一个家长有两个孩子在同一范围内只收一条通知、回执一次,两个孩子都算已回。
11. **AI 审核开关的含义**:只管 AI 生成的评语给不给家长看(F1);M4 不做"退步建议推家长"这类主动推送(spec 里没有落到具体功能)。
