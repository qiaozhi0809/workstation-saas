### SSE 格式

响应头 `Content-Type: text/event-stream; charset=utf-8`、`Cache-Control: no-cache`、`X-Accel-Buffering: no`。每个事件是 `event: <名>\ndata: <JSON>\n\n`:

| 事件 | data | 何时 |
|---|---|---|
| `meta` | `{message_id?: string, item_id?: string}` | 开始时一次(reply 给新建的助手消息 id;run 给条目 id) |
| `delta` | `{text: string}` | 每段新文字(已换回真名) |
| `done` | `{status: 'done' \| 'stopped'}` | 正常结束 |
| `error` | `{code: string, message: string}` | 服务商出错(此后流结束;消息 / 条目状态已落库为 `error` / `err`) |

在开始推流**之前**发现的问题按普通 HTTP 错误返回(下表),前端据此区分"没开始"和"中途出错"。

### 错误码(新增;M2a / M2b 的照旧)

| code | HTTP | 何时 |
|---|---|---|
| `NOT_FOUND` | 404 | 学生不在本学年在籍;记录 / 评语 / 对话 / 条目不存在或不属于调用者;`review_id` 不属于本班 |
| `FORBIDDEN` | 403 | 缺权限;删除别人的成长记录且不是班主任(`action`=`growth.delete`);撤销别人的点评(`action`=`review.revoke`);模板所需权限不足(`action` 为缺的那个权限点) |
| `RECORD_READONLY` | 409 | 删除往年的成长记录 / 评语 |
| `NO_ACTIVE_YEAR` | 409 | 写成长记录 / 评语时学校没有进行中的学年 |
| `AI_NOT_CONFIGURED` | 409 | reply / run 时学校还没配置 AI 服务 |
| `AI_BUSY` | 409 | 该对话正在生成 |
| `AI_FIELD_INVALID` | 400 | 模板字段缺失 / 不合法 / 学生不在本班 / 考试不可见;`details: {field}` |
| `AI_NO_TARGETS` | 400 | 退步同学家长沟通:没有退步 5 名及以上的同学 |
| `AI_BATCH_ONLY` | 409 | 批量对话里追问 / 重新生成 |
| `AI_NOTHING_TO_REPLY` | 409 | 不带 text、不 regenerate,而最后一条用户消息已有回复 |
| `BAD_REQUEST` | 400 | 请求体校验失败(沿用 M1 处理器) |

SSE `error` 事件里的 code(服务商错误,原文提示由后端给出中文):`AI_KEY_INVALID`(401/403)、`AI_MODEL_NOT_FOUND`(404)、`AI_QUOTA`(402)、`AI_RATE_LIMITED`(429)、`AI_UPSTREAM`(≥ 500 或回包无法解析)、`AI_UNREACHABLE`(连接失败 / 超时)。

### 规则补充

- **成长记录**:新增时挂学生本学年的注册记录(`enrollment_id`、`class_id`、`academic_year_id` 一并存)。删除:记录必须是本学年的(否则 409 `RECORD_READONLY`);调用者是记录人(且仍有 `growth.write`),或在记录所在班有 `homeroom_teacher` 绑定;否则 `deny(action='growth.delete', object_type='growth_record')`。`can_delete` 按同样规则算。审计 `growth.create` / `growth.delete`(`object_type`=`student` / `growth_record`,不记内容)。
- **评语**:`semester` = `f"{学年名} {第一学期|第二学期}"`,按学校时区今天的月份:8–12 月与 1 月为第一学期,2–7 月为第二学期。删除:本学年的、调用者有 `comment.write`;往年 409。`bulk` 里每个 `student_id` 必须是本班在籍,否则 400 `AI_FIELD_INVALID`(`details.field`=`items`),整批不写。审计 `comment.create`(bulk 记一条,`extra: {count}`)/ `comment.delete`。
- **点评单条撤销**:只撤这一行(`revoked_at`、`revoked_by_user_id`);已撤销的返回 `revoked: 0`;不是给分人 → `deny(action='review.revoke', object_type='review')`。审计 `review.revoke`(`object_type`=`review`)。
- **AI 模板权限**:每个模板声明所需权限点(全部满足才可用),在请求的班级上判定:`lesson / ppt / homework / birthday` = `ai.use`;`report` = `ai.use` + `exam.read`;其余 10 个 = `ai.use` + `ai.class`(`comments` / `comment1` 还要 `comment.write`)。自由对话 = `ai.use`;勾选的资料按权限裁剪,不报错。`unavailable_reason`:缺 `ai.class` → `仅班主任可用`;缺 `exam.read` → `需要查看成绩的权限`。
- **字段校验**:`student` = 本班在籍的 `student_id`;`students` = 1–80 个不重复的本班在籍 `student_id`;`exam` = 调用者可见的本班考试 id;`exam0` = 同上或 `null`(`report` 缺省时取被分析考试的前一场,没有就不对比);`select` 值必须在 `options` 里(缺省取 `default`);`text` ≤ 100 字、`textarea` ≤ 2000 字;必填项为空 → `AI_FIELD_INVALID`。
- **对话标题**:模板 = `模板标题 · 关键字段`(lesson / ppt = `{学科}《{课题}》`;homework = `{学科}「{知识点}」`;meeting = 主题;activity = 活动名称;summary = 类型;notice = 事项前 20 字;parent / talk / birthday / comment1 = 学生姓名;pmeeting / report = 考试名;comments = `{n} 位同学`;parent-batch = `{考试名} · {n} 位同学`);自由对话 = 文字前 20 字(超出加 `…`)。
- **reply**:`text` → 先追加用户消息再生成;`regenerate` → 删掉最后一条助手消息再生成;都没有 → 最后一条用户消息还没有回复才生成,否则 409 `AI_NOTHING_TO_REPLY`。发给服务商的消息 = 系统提示 + 历史(用户消息用存下的 `sent`,助手消息把真名重新脱敏)+ 当前用户消息。
- **生成落库**:开始时建助手消息(`streaming`),结束时写最终内容与状态;`streaming` 且 `updated_at` 早于 2 分钟的消息在读对话时显示为 `error`、`error`=`上次生成被中断了,可以点「重新生成」`(内容保留)。批量条目同理:`run` 超过 2 分钟显示为 `wait`。
- **并发锁**:Redis 键 `ai:chat:{chat_id}`,`SET NX EX 300`;拿不到 → 409 `AI_BUSY`;生成结束(任何结局)释放。
- **审计**:每次生成一条 `ai.generate`(`object_type`=`ai_chat`,`object_id`=对话 id),`extra: {template, student_ids, provider, model, masked, outcome: 'done'|'stopped'|'error', prompt_tokens, completion_tokens, chars_in, chars_out}`(服务商没回 usage 时两个 tokens 为 null);"复制提示词"一条 `ai.prompt_copy`(`object_type`=`class`,`extra` 同上去掉 provider / model / tokens / outcome)。`student_ids` = 本次 prompt 里出现资料的学生(单生、批量条目、`students` 字段)。
- **隐去姓名**:替换表 = 本班全部注册记录(含已删除、已转出)的学生姓名,长度 ≥ 2 的才替换,长名优先;编号 `【学生{mask_no:02d}】`;换回时用同一张表,未知编号原样保留。学校 `mask_forced` 时忽略请求里的 `mask`。
