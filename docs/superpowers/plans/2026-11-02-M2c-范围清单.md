# M2c AI 与学年 · 范围清单

> 本文件逐项记录原版 AI 助手(PRD `reference-html/features-extracted.md` §9、附录 A)、档案抽屉"成长记录 / 评语"页签(§1.7、§6.3.4、§6.3.5、§6.7)、原版设置里的 AI 接口(§10.6),以及 spec §3.3 学年升级、§6 AI 层在新项目里的处理方式。
> 实施计划见 [`2026-11-02-M2c-AI与学年.md`](2026-11-02-M2c-AI与学年.md)。

## 用户拍板(2026-11-02)

1. **导出 Word 保留**,照原版做法:前端把回复渲染成 HTML,存成 `.doc`(宋体 12pt、UTF-8 BOM),不加依赖。
2. **AI 服务商首发内置 6 家国内服务商 + 自定义**:DeepSeek、通义千问(阿里云百炼)、Kimi(月之暗面)、智谱 GLM、豆包(火山方舟)、硅基流动,外加"自定义(OpenAI 兼容接口)"。全部走同一个 OpenAI 兼容适配器;不做 Claude / Ollama 的专门适配(Ollama 等本地模型可用"自定义"接入)。
3. **API Key 加密存库,M2c 用命令行配置**:照 spec §8.2,Key 用 AES-256-GCM 加密存在学校设置表里,主密钥放服务器配置(`WS_MASTER_KEY`);M2c 提供 `ai-config` 命令(查看 / 设置 / 测试连接 / 清除),M3 管理端只需加页面。新增后端依赖 `cryptography`。
4. **学年升级做后端完整流程 + 命令行**:生成升级建议表(升年级 / 毕业 / 留级 / 转出、班主任跟班、任课老师沿用)→ 预览 → 执行 → 回滚(新学年还没录任何数据时才允许),全部在后端并有测试;用 `year-upgrade` 命令操作。向导页面随 M3 管理端。
5. **14 个 prompt 模板按原意重写**:保留每个模板的字段、结构和写作要求,文字由计划重新撰写,不照搬原项目文本(原项目为非商业许可,与本项目分离)。
6. **AI 对话记录存服务器,仅本人可见**:换电脑也能接着用;只有发起的老师自己能看、能删;"最近对话"列表同原版。
7. **成长记录:班主任 + 副班主任可写,跟着学生走**:任课老师和校领导只读;删除只限记录的人或班主任,且只能删本学年的;升学年后新班主任能看到往年记录(只读)。
8. **新依赖全部批准**:后端 `httpx`(由开发依赖改为运行依赖,流式调用 AI)、`cryptography`;前端 `react-markdown@^9`、`remark-gfm@^4`(渲染 AI 回复的 Markdown 与表格,默认不执行 HTML)。

## 计划自定项(未单独问用户,写在这里供审阅)

- **AI 权限按 spec §6.3 表**:备课 / 课件 / 分层作业 / 生日祝福 / 自由对话 = 本班任何老师(班主任、任课、副班主任);成绩分析报告 = 能看成绩的老师(任课老师只看本科目);班会 / 活动 / 总结 / 家长通知 / 家长沟通 / 家长会发言稿 / 期末评语 / 谈心提纲 / 退步同学家长沟通 = 仅班主任。校领导的 AI 入口随 M3。
- **喂给 AI 的资料按调用者权限裁剪**:任课老师的学生档案里没有家庭信息、成绩只有本科目;没有 `review.read` 的不带点评,没有 `growth.read` 的不带成长记录。家长姓名、电话等联系人信息**任何情况下都不发**(同原版)。
- **额外的号码过滤**:不论是否"隐去姓名",发出去的文字里形如手机号(`1[3-9]` 开头 11 位)和 18 位身份证号的内容一律替换成"〔号码已隐去〕"(原版没有;老师在家庭备注里写了电话也不会外发)。
- **脱敏编号**:学生新增永久编号 `mask_no`(全校递增,不随改名 / 改学号变化,也不是数据库主键),AI 里写作 `【学生07】`。隐去姓名默认开;学校可强制开(`ai-config set --mask-forced`),强制时老师不能关。替换表是本班全部注册记录(含已删除、已转出)的学生姓名;往年成长记录里若写了别班同学的名字,不在替换范围内(已知限制)。
- **流式输出**:后端用 SSE 推给前端;编号换回真名在**后端**做,并处理"一个编号被拆在两段里"的情况。
- **评语学期**:评语自动记"学年 + 学期",8 月至次年 1 月为第一学期,2–7 月为第二学期(原版是设置里的自由文本)。
- **点评撤销按单条**:档案里的"撤销"只撤这一位同学的这一条(原版行为);全班 / 小组加分在教室里仍按整次撤销。只能撤自己给的。
- **学年升级后旧注册记录状态记 `promoted`**(新增枚举值),毕业记 `graduated`,转出记 `transferred`;所有历史事件不动。

## 逐项清单

标记:**对标** = 行为与原版一致(画面自绘 / 用新组件);**改** = 行为按 B 端需要调整;**新增** = 原版没有;**后移** = 依赖后续里程碑;**删除** = 不做。
