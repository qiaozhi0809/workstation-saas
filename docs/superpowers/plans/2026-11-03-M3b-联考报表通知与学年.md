### 月度考勤报告(`school.view`,且对相关班有 `attendance.read`)

```ts
interface AttendanceCounts { days: number; expected: number; present: number; leave: number; absent: number; late: number; rate: number | null }   // rate 0..1
interface AttendanceReport {
  month: string; scope_label: string
  classes: ({ class_id: string; class_name: string; grade_name: string } & AttendanceCounts)[]
  total: AttendanceCounts
}
interface AttendanceClassDetail {
  month: string; class_id: string; class_name: string; days: number
  students: { student_id: string; name: string; student_no: string | null; leave: number; absent: number; late: number }[]   // 缺勤多到少,再请假、迟到、学号
}
```

| 方法 | 路径 | 响应 | 说明 |
|---|---|---|---|
| GET | `/admin/reports/attendance?month=&grade_id=` | `AttendanceReport` | `month` 默认本月;`grade_id` 可省 |
| GET | `/admin/reports/attendance/class?month=&class_id=` | `AttendanceClassDetail` | 该月在这个班注册过的学生都列(含已转出) |
| GET | `/admin/reports/attendance/export?month=&grade_id=` | `text/csv` | 每班一行 + 合计行;审计 `attendance.export` |

口径(范围清单 I 节):`days` = 该班该月 `attendance_days` 的天数;`expected` = 每个记录日在读人数之和(`entered_at` 的学校本地日期 ≤ 当天,且 `left_at` 为空或本地日期 > 当天);`present = expected − leave − absent`;`rate = present / expected`(`expected = 0` 时 null);请假 / 缺勤 / 迟到只计记录日内的。`total.days` = 各班 `days` 之和。

### 实时推送

- 端点:`GET /api/v1/ws`(WebSocket)。客户端连上后 5 秒内发 `{"type":"auth","token":"<access token>"}`;令牌有效且账号 `active` 且不需要改密码 → 服务器回 `{"type":"ready"}`;否则以代码 `4401` 关闭。认证前不推任何事件。
- 服务器事件:`{"type":"notice.new","id","title","from_name","created_at"}`、`{"type":"notice.recalled","id"}`、`{"type":"session.revoked"}`、每 25 秒 `{"type":"ping"}`。客户端发来的其他消息一律忽略。
- 后端发布:`app.ws.hub.publish(redis, user_ids: list[UUID], event: dict) -> None`(同步,业务代码在事务提交**之后**调用),写 Redis 频道 `ws:events`,消息 `{"user_ids": [...], "event": {...}}`;每个进程一个订阅任务,把事件转给本进程里属于这些用户的连接。
- 冻结账号:M3a 的 `accounts.service.freeze()` 在 `db.commit()` 与 `sessions.revoke_all()` 之后 `publish([user_id], {"type": "session.revoked"})`(不动 `last-admin` advisory lock 与提交顺序);连接收到后服务器随即关闭该用户的全部连接(代码 `4403`)。
- 开发代理:`apps/web/vite.config.ts` 的 `/api` 代理加 `ws: true`。
