## Global Constraints

- 沿用 M4b 计划的 Global Constraints(依赖、后端写法、权限、审计、提交身份、仓库公开、本地降载、令牌不进 URL、学校时区)。
- **M5a 不加迁移**;后端只新增 `app/deploy/**`、`app/version.py`,改 `cli.py`、`logging.py`、`main.py`(只追加路由行)、`lifecycle.py`(L85 一处)。
- **脚本**:`#!/usr/bin/env bash` + `set -euo pipefail`;只用 bash 5、coreutils、`docker`、`docker compose`、`tar`、`sha256sum`、`openssl`(生成随机密钥);`shellcheck -S warning` 无告警;所有用户可见输出为中文;非交互模式全部参数可由环境变量 `WS_INSTALL_*` 给出。
- **离线**:安装、备份、恢复、升级都不访问外网(`acme` 证书模式除外,由用户选择)。
- **密钥**:`.env` 权限 600;脚本不把密钥打印到终端、日志或诊断包;诊断包里所有键名含 `secret` / `key` / `password` 的值、`database_url` / `redis_url` 里的密码一律替换为 `***`。
- **镜像标签** = 版本号(去掉开头的 `v` 与 `-m5a-deploy` 这类后缀,如 `0.7.0`);`APP_VERSION` 在构建时写进镜像(`--build-arg WS_APP_VERSION`)。
- **端口**:对外只开 `web` 的 80 / 443(可用 `WS_HTTP_PORT` / `WS_HTTPS_PORT` 改);postgres、redis、app 只在 compose 内网;内网固定子网 `172.30.0.0/24`,`.env` 里 `WS_TRUSTED_PROXIES=172.30.0.0/24`。
- 新增审计动作:`system.diagnostics`(导出诊断包)、`system.init`(初始化学校);`audit/labels.py` 加分组 `system`"系统"。
- 提交身份同 M4b(段会话与实现子代理 `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`;Opus 终审自己提交时写 Opus)。

## Review Focus

1. **装到一半断了再装一次**:第二次 `install.sh` 不能重新生成密钥(否则 AI Key 等加密字段全部解不开)、不能建第二个学校或管理员。落点:Task 2 `test_init_school_idempotent`;Task 6 `deploy/tests/install_twice.sh`。
2. **升级时迁移预检不通过**:必须停在旧版本、旧服务继续可用、给出可读报告和定位 SQL,而不是起一个半迁移的新版本。落点:Task 1 `test_precheck_blocks_dirty_0002`;Task 6 `deploy/tests/upgrade_precheck_fail.sh`。
3. **恢复别的版本 / 损坏的备份**:校验和不对、主版本号不同、文件不完整都要在动数据库之前拒绝。落点:Task 7 `deploy/tests/restore_rejects.sh`。
4. **诊断包泄露**:密钥、数据库密码、手机号、令牌不能出现在 zip 里;非 `settings.manage` 的账号拿不到。落点:Task 4 `test_diagnostics_masks_secrets`、`test_diagnostics_requires_settings_manage`。
5. **定时任务重启 / 跑两遍**:`scheduler` 容器在 03:10 前后重启,当天的归档只跑一次;归档出的账号已打开的页面被踢下线(L85)。落点:Task 3 `test_job_runs_once_per_day_across_restart`、`test_archive_publishes_revoked`。

## 契约(冻结)

### 命令行(`python -m app.cli …`)

| 命令 | 参数 | 退出码 | 输出 |
|---|---|---|---|
| `migrate` | `--check-only`(只预检,不迁移) | 0 通过 / 已是最新;2 预检不通过;1 其他错误 | 预检报告(见下)、`已迁移到 0010` |
| `init-school` | `--name <校名>`(1–50 字)`--admin-login <登录名>`(3–32 字,字母数字 `._-`)`--admin-password-stdin`(从标准输入读一行) | 0 已初始化;3 已初始化过(不改任何数据);1 参数错误 | `已创建学校「…」和管理员 …`、`已初始化过,未做任何改动` |
| `scheduler` | `--once`(跑一次到期任务就退出,测试用) | 常驻 | 每次执行任务打一行 JSON 日志 |
| `parent-archive` | 同现有 | 同现有 | 同现有(内部改为发布 `session.revoked`,L85) |

### HTTP(管理端,`settings.manage`)

```ts
interface SystemInfo {
  version: string                 // APP_VERSION
  migration: string               // alembic 当前版本,如 "0010"
  started_at: string              // 本进程启动时刻
  db_size_bytes: number
  last_backup: { at: string; file: string; size_bytes: number } | null   // 读 /var/log/workstation/backup-last.json,没有为 null
}
```

| 方法 | 路径 | 响应 | 说明 |
|---|---|---|---|
| GET | `/admin/system/info` | `SystemInfo` | |
