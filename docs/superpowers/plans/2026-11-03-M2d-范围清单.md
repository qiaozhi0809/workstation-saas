# M2d 桌椅排列 · 范围清单

> 本文件逐项记录原版 v1.1.0(2026-11-02,上游提交 `a49bd54`,相对我们的基线 v1.0.0 / `0bcff76`)新增与改动的功能在新项目里的处理方式。基线说明见 [`reference-html/BASELINE.md`](../../../reference-html/BASELINE.md),v1.1 功能摘要见 [`features-extracted.md` 附录 D](../../../reference-html/features-extracted.md)。
> 实施计划见 [`2026-11-03-M2d-桌椅排列.md`](2026-11-03-M2d-桌椅排列.md)。

## 为什么是独立的 M2d

- v1.1 只改了一块:班级设置 · 桌椅排列。它属于 M2 的目标"一位班主任可用新系统完整替代原 HTML",改动集中在教室画面与排座(M2a 的范围)、学生名单联动(M2b)和学年升级(M2c)。
- 放进 M3 会和组织架构、通知 / WebSocket 这些大块绑在一起,迟迟不能交付;单独做一个小里程碑,排在 M2c 之后、M3 之前。
- 读完代码后没有发现必须并入 M3 的理由:M3 的"班级信息设置"页以后只需要展示本里程碑的结果(见 G3)。

## 用户拍板

1. **范围(2026-11-02 调研后定)**:调研报告 #1–#8 全部接入,含讲台两边的单人桌和教室名称,照"不精简、先复刻原版"来;#9 原作者署名不跟;#10 原版旧数据迁移不需要(我们是新库),但我们自己已有班级的座位数据要迁移,默认"自己设定、双人同桌"。
2. **排期**:独立小里程碑 M2d,排在 M2c 之后、M3 之前。
3. **班级名称只读(2026-11-03)**:班级设置对话框里显示班级名称但不能改,改名留给 M3 组织架构;对话框里只有"教室"可填。
4. **学年升级清空教室名称(2026-11-03)**:升年级常换教室,新学年班级的教室名称置空,桌椅排列(每桌人数、行列方式、学号顺序、讲台两侧座位、排数与列数)照旧沿用。
5. **排数保留 1~12(2026-11-03)**:"自己设定"的排数沿用 M2a 已上线的 1~12(原版 2~10 是它的子集,不收窄已有数据);"按人数自动排"照原版算在 4~10 排之间。
6. **入口(2026-11-03)**:底部操作台"⋯ 更多操作"菜单加"班级设置";排座操作条用"桌椅排列"按钮替换现在的"N 排 × M 列"弹层。不在舞台上加齿轮悬浮钮。

## 逐项清单

标记:**对标** = 行为与原版一致(画面自绘 / 用新组件);**改** = 行为按 B 端需要调整;**新增** = 原版没有;**后移** = 依赖后续里程碑;**删除** = 不做。

## 数据迁移(我们自己的已有班级)

迁移 `0005` 对已有班级:

- `desk_size = 2`(双人同桌)、`seat_layout = 'manual'`(自己设定)、`seat_order = 'row'`、`podium_left = podium_right = 0`、`room = ''`;
- `seat_rows` 不变;`seat_cols` 为奇数的(M2a 允许 1~12 任意列数)**加 1 变成偶数**,只在最右边多出一列空座,**任何同学的座位都不动**;
- 已有座位、固定状态、座位版本号都不变;历史排座快照 `seat_arrangements` 补 `desk_size = 2`、讲台两侧 0。

新建班级(以后 M3 建班、学年升级里的"新建班级")默认 `desk_size = 2`、`seat_layout = 'auto'`。

## 计划自定项(请审阅时留意)

1. **座位编码**:讲台边座位用"第 0 排 + 负列 / 正列"存在已有的 `seat_row` / `seat_col` 里,不新增座位表;接口里也是同样的 `row` / `col`。这样已有的唯一索引、固定座位约束、排座快照都不用改结构。
2. **"每排桌数"按座位数存**:`seat_cols` 保持"每排座位数"的含义(M2a 起所有代码都这样用),桌数 = `seat_cols / desk_size`,只在对话框里换算显示。
3. **算法只在后端一份**:自动排、按学号重排、找空位都在后端;对话框预览调后端预览接口。随机打乱 / 男女同桌 / 优带弱仍是前端草稿算法(M2a 起如此),只是按桌型泛化。
4. **排座保存不再改行列**:`PUT /classes/{id}/seating` 的 `rows` / `cols` 必须等于班级当前值,否则 400(`layout_mismatch`);行列只经"桌椅排列"改。
5. **固定座位与重排**:见 D5。
6. **权限**:桌椅排列、教室名称都用已有的 `seating.write`(只有班主任有),不新增权限点;写审计 `class.layout`。
7. **讲台边座位可以固定**:不报错,但对算法没有额外效果(本来就不动)。
8. **没有学号的同学排在最后**:按学号重排时,原版把学号为空的排在最前;新系统排在最后(没有学号的多半是刚转来的同学)。学号相同再按姓名(按字符顺序)。
9. **版本号**:tag `v0.4.5-m2d-desks`(合并后由 M2d 协调会话打,需用户批准)。
