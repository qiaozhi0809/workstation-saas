### 2.2 混合路线：哪些用 Arc，哪些不用

| 件 | 来源 | 理由（来自 Arc 文档或源码） |
|---|---|---|
| `Button` | Arc `button`，经适配层 | 原生 `<button>`，角色不变，有按压反馈和 `loading`。但每个按钮带一个 ResizeObserver（Arc 文档原话：avoid hundreds in a long list），所以**表格行内的操作按钮走适配层的项目实现**（`variant="link"` 或 `IconButton`） |
| `Badge` | Arc `badge`，经适配层 | 有 `tone`、`dot`、`size`；默认不是药丸（`pill=false`） |
| `Tooltip` | Arc `tooltip` | 用于截断文本和图标按钮。它只支持 `side: top | bottom`，所以侧栏 rail 的右侧提示另做 `RailTip`（Task S-2，直接用 `@radix-ui/react-tooltip`，`side="right"`） |
| `Skeleton` | Arc `skeleton` | 只画文本行和头像（Arc 文档原话：build custom shapes for grids）。`LoadingState variant="form"` 用它，`table` / `cards` 两种骨架自己画 |
| `Input` / `Textarea` | 项目实现 | Arc `Input` 的 `label` 是必填，还自带说明和报错行、每个字段一个 ResizeObserver；我们 43 处 `Input` 都配外部 `Label`，成绩录入表里有上百个输入框 |
| `EmptyState` | 项目实现 | Arc 的是居中样式、`description` 必填；我们有 140 处调用，规格要求跟随区块标题左对齐 |
| `NativeSelect` / `Checkbox` / `Switch` | 项目实现（原生） | 换成 Radix 要重写 326 处 `fireEvent.change`（52 个文件）里的相关部分、e2e 12 处 `selectOption` 和 19 处 `.check()`；原生 `<select>` 在平板上弹系统选择器 |
| 侧栏 / 页头 / 容器 / 表格 | 项目实现 | Pro 侧栏区块的导航数据写死在源码里（`WorkspaceSidebarProps` 只有 `className / onNavigate / defaultCollapsed / onCollapsedChange`），要用只能 fork（Q3） |
