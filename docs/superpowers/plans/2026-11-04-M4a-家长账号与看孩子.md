**Goal:** 班主任给学生建家长账号;家长用手机浏览器登录,看孩子的今日出勤与点评、迷你教室里的座位、成长记录与评语、考试成绩和档案,主家长能改家庭联系人;孩子毕业或离校后家长账号转为只读历史,满 365 天归档;顺带修 L12 前半、L32、L50。

**Architecture:** 迁移 `0009` 给 `parent_links` 加只读 / 归档状态、给 `comments` 加"家长可见"。家长身份走已有的 `role_bindings`(`primary_parent` / `secondary_parent`,`scope = {student_id}`,学年为空),与 `parents`、`parent_links` 三处一起写。家长端的读接口单独放在 `/parent/children/{student_id}/…`,服务层复用教师端已有的取数函数,先用 `child_link_or_deny` 判定绑定再取数。前端新增第三个视图 `roles/parent/`(手机优先的壳 + 今日 / 成长 / 成绩 / 档案),`ClassroomMap` 加 `highlight`,迷你教室只拿到"哪些座位有人"和自己孩子的座位。HTTP 契约在本计划中冻结,后端段与前端段并行。

**Tech Stack:** 沿用 M3b;**不新增任何依赖**。

**Spec:** [`docs/superpowers/specs/2026-11-01-三角色协作平台-design.md`](../specs/2026-11-01-三角色协作平台-design.md) §2.1–§2.6(家长角色、数据边界、字段级权限、学校开关)/ §3.2(Parent、ParentLink、Comment)/ §3.5(家长首页索引)/ §4.4(`mode: mini`、`highlight`)

### 班主任管家长(`parent.manage`,作用域 = 学生当前在读注册的班)

```ts
type ParentRelation = '父亲' | '母亲' | '祖辈' | '其他'
interface ParentOfStudent {
  link_id: string; user_id: string
  name: string                 // parents.name,家长称呼
  relation: ParentRelation; phone: string
  is_primary: boolean
  status: 'active' | 'readonly'
  account_status: 'active' | 'frozen' | 'archived'
  shared_account: boolean      // 这个账号还有教职工身份(不能由班主任重置)
  must_change_password: boolean
}
interface ParentInput { phone: string; name: string; relation: ParentRelation }   // name 1..20,去首尾空格
interface ParentCreated { parent: ParentOfStudent; temp_password: string | null } // 绑到已有账号时 null
```

| 方法 | 路径 | 请求 | 响应 | 说明 |
|---|---|---|---|---|
| GET | `/students/{student_id}/parents` | — | `ParentOfStudent[]` | 主家长在前,再按绑定时间;不含 `ended` |
| POST | `/students/{student_id}/parents` | `ParentInput` | 201 `ParentCreated` | 见下"添加规则";审计 `parent.create`(新账号)或 `parent.link`(已有账号) |
| POST | `/parent-links/{link_id}/primary` | — | `ParentOfStudent[]` | 原主家长改次要;三处一起改;审计 `parent.primary` |
| DELETE | `/parent-links/{link_id}` | — | 204 | 绑定 `ended`;账号没有任何在用绑定时改 `archived` 并 `revoke_all`;解绑的是主家长且还有次要家长时,最早的次要家长升为主家长;审计 `parent.unlink` |
| POST | `/parent-links/{link_id}/reset-password` | — | `{temp_password: string}` | `shared_account` 为真 → 409 `PARENT_ACCOUNT_SHARED`("该账号也是教职工账号,请联系信息中心重置");账号非 `active` → 409 `ACCOUNT_NOT_ACTIVE`;成功后 `must_change_password = true`、`revoke_all`、清登录锁定;审计 `parent.reset` |
| PUT | `/comments/{comment_id}/parent-visible` | `{visible: boolean}` | `CommentOut` | 需要该评语所在班的 `comment.write`;审计 `comment.share` / `comment.unshare` |

**添加规则**(`POST /students/{id}/parents`,先锁学生行 `SELECT … FROM students WHERE id = :s FOR UPDATE` 再判定):
1. 手机号不合规 → 400 `PHONE_INVALID`。
2. 找本校 `active` 账号:`lower(login_name) = 手机号` 或 `phone = 手机号`。多于一个 → 409 `PHONE_AMBIGUOUS`("这个手机号对应多个账号,请联系信息中心")。存在非 `active` 账号占用该登录名 → 409 `PHONE_TAKEN_INACTIVE`("这个手机号的账号已停用,请联系信息中心")。
3. 已有账号且已绑这个孩子(未 `ended`)→ 409 `PARENT_EXISTS`;曾绑过但已 `ended` → 把那条绑定恢复为 `active`(不新增行)。
4. 这个孩子未 `ended` 的绑定已有 4 条 → 409 `PARENT_LIMIT`("每个孩子最多 4 位家长")。
5. 没有账号:建 `users`(`login_name = phone = 手机号`、`display_name = name`、`must_change_password = true`、临时密码 `generate_temp_password()`)。
6. `parents` 行没有就建(`name`、`phone`);已有不改名。
7. 写 `parent_links`(`relation`、`is_primary` = 这个孩子还没有未 `ended` 的主家长、`status = 'active'`)与 `role_bindings`(`primary_parent` 或 `secondary_parent`,`scope = {"student_id": …}`,`academic_year_id = NULL`)。

### 家长端读接口(调用者对该孩子有未过期的绑定)

```ts
interface ParentChild {
  student_id: string; name: string; gender: string | null
  class_name: string | null; grade_name: string | null     // 在读班;只读历史时为最后一个班
  relation: ParentRelation; is_primary: boolean
  status: 'active' | 'readonly'
  left_on: string | null        // 只读时:变为只读那天(学校本地日期)
  archive_on: string | null     // 只读时:left_on + 365 天
}
interface MiniSeatMap {
  rows: number; cols: number; desk_size: 1 | 2 | 3
  podium_left: number; podium_right: number
  occupied: { row: number; col: number }[]      // 全部有人的座位(含自己孩子),不带身份
  mine: { row: number; col: number } | null     // 自己孩子没有座位时 null
}
interface ParentReview { id: string; reason_text: string; score_delta: number; subject: string | null; given_at: string; given_by_name: string | null }
interface ParentToday {
  date: string                                  // 学校本地日期
  status: 'active' | 'readonly'
  attendance: { status: 'present' | 'leave' | 'absent' | 'late'; reason: string | null } | null   // 未确认且无记录时 null
  attendance_confirmed: boolean
  reviews: ParentReview[]                       // 今日,时间倒序
  week_points: number                           // 本周(周一起)积分,口径同教室积分榜;负向点评关时只加正分
  class_info: { class_name: string; homeroom_name: string | null; teachers: { subject: string; name: string }[] } | null
  enrollment_id: string | null                  // 只读时 null
  seat_map: MiniSeatMap | null                  // 只读时 null
}
type ParentProfile = Omit<StudentProfile, 'teacher_notes'> & { can_edit_contacts: boolean }
interface ParentGrowthRecord { id: string; type: GrowthType; date: string; content: string; year_name: string; created_by_name: string | null }
interface ParentComment { id: string; semester: string; content: string; created_at: string }
interface ParentExamItem { id: string; name: string; exam_type: ExamType; date: string; year_name: string; class_name: string }
interface ParentExamDetail {
  exam: ParentExamItem
  subjects: { name: string; full: number; score: number | null; class_avg: number | null; class_max: number | null }[]
  total: number | null; total_full: number
  ranked: number                       // 有总分的人数
  class_rank: number | null            // 只在"家长可见排名"开时给
  band: '前 10%' | '前 30%' | null     // 只在开关关时给;ranked < 10 时 null
}
```
