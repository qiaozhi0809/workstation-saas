# M2a.5 · UI 基础与打磨 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
>
> **开始前先读 [`../../../AGENTS.md`](../../../AGENTS.md)、[范围清单](2026-11-01-M2a5-范围清单.md) 和 spec。** 本计划在 `v0.2.0-m2a-classroom` 打标之后执行,建立在该 tag **实际合并的代码**之上;与本文不一致处以代码为准,计划中的文件行号、类名以执行时的代码为准做最小修正,并写进 PR 的"偏差"小节。

**Goal:** 在 M2b 大量新增页面之前,给前端打好 UI 地基:设计令牌(浅色 + 深色)、shadcn/ui 组件、响应式应用外壳、统一的加载 / 空 / 错误状态、基础无障碍;并把现有全部页面迁移过去。**只改 UI,不改行为和接口。**

**Architecture:** 颜色、圆角全部改为 `:root` / `.dark` 上的 CSS 变量,经 Tailwind theme 映射成语义类名(`bg-background`、`text-muted-foreground`、`text-warning`……);迁移期间旧色名(`ink`、`line`、`panel`……)暂时作为别名指向新变量,保证各段可并行迁移,最后一段删除别名并加防回退测试。shadcn 组件生成到 `src/shared/components/ui/`,所有弹层通过项目自己的 `Modal` / `SidePanel` 包装使用,包装层负责接入现有的 Esc 层级栈和全屏挂载点。教室 SVG 画面不动。

**Tech Stack:** 沿用 M1/M2a;新增 shadcn/ui(CLI 固定 `shadcn@2.3.0`,new-york 风格,neutral 基色,CSS 变量)及其运行时依赖:`class-variance-authority`、`tailwind-merge@^2.6.0`、`tailwindcss-animate`、`lucide-react`、`@radix-ui/react-{dialog,slot,label,separator}`。

**Spec:** [`docs/superpowers/specs/2026-11-01-三角色协作平台-design.md`](../specs/2026-11-01-三角色协作平台-design.md) §1.2(技术栈 UI = Tailwind CSS + shadcn/ui)、§4.4(ClassroomMap)、§4.6(全屏投屏保留)、M4 家长端为响应式 Web(§1.1、§4)

## Global Constraints

- 版本锁定:React `18.3.x`、Vite `5.4.x`、Tailwind `3.4.x`、TypeScript `~5.6`;**不得升级到 Tailwind 4 / React 19**。
- shadcn CLI 一律写成 `npx shadcn@2.3.0 ...`(2.3.0 是最后一个支持 Tailwind 3 的版本),**禁止** `shadcn@latest` / `shadcn-ui`。
- `tailwind-merge` 必须是 `^2.6.0`(3.x 只支持 Tailwind 4,会悄悄合并错类名);每次运行 shadcn CLI 之后执行 `npm ls tailwind-merge` 确认仍是 2.x。
- 新增运行时依赖仅限 Tech Stack 列出的几个;需要其他 shadcn 组件或依赖时停下,用 SendMessage 报告协调会话。
- **只改 UI**:不改 `server/`、HTTP 契约、查询键、store、业务逻辑;用户可见文案和可访问名称保持不变,**仅**允许 [文案变更表](#文案变更表) 列出的改动。
- **教室 SVG 不改**:`ClassroomMap/art/`、`ClassroomMap/effects/`、`seatParts.tsx`、`SeatLayer.tsx`、`DeskLayer.tsx`、`classroom.css` 内的颜色、形状、动画全部保持原样(spec D05 / M2a 段 B 视觉规范)。
- 颜色只能用语义令牌类(`bg-background`、`text-foreground`、`text-muted-foreground`、`border-border`、`bg-primary`、`text-destructive`、`text-success`、`text-warning`、`text-info`……);**不得**在 TSX 里写 Tailwind 调色板色(`text-red-500`)、`bg-white` / `text-black`、任意十六进制(`bg-[#f5f5f4]`)。Task 16 起由测试强制。
- 弹层只能用 `Modal` / `SidePanel`(Task 2),**不得**在页面里直接用 `ui/dialog` / `ui/sheet`:包装层负责 Esc 层级栈(含中文输入法保护)和全屏挂载点。
- 舞台内浮层(点名卡 `PickCard`、点评弹层 `ReviewPopover`、悬停卡 `HoverCard`)保持"舞台内绝对定位、不走 portal",只换令牌样式(它们依赖舞台坐标,且要随舞台进入全屏)。
- 原生 `<select>`、`checkbox`、`radio`、`type="date"` 保留为原生控件,只加令牌样式(现有测试全部用 `fireEvent`,项目没有 `user-event`;原生控件在平板和手机上也更好用)。不引入 Radix Select / Checkbox / RadioGroup / Tabs / DropdownMenu / Tooltip。
- 动效:所有新增动画和过渡在 `prefers-reduced-motion: reduce` 下关闭。
- 测试:现有 Vitest 和 Playwright 全部保持通过;因 DOM 结构变化必须改的测试断言,只改定位方式,不放宽断言含义,并逐条写进 PR"偏差"。
- 不写估时,不写占位符;Conventional Commits;每个 task 至少一次 commit。

## Review Focus

以下五条是 spec 没写明、但最可能咬到真实老师的输入 / 失败模式,测试已落在对应 task:

1. **中文输入法里按 Esc 关掉了对话框**:老师在"编辑黑板"里用拼音输入,按 Esc 取消候选词,结果整个对话框被关、内容丢失(Radix 自带的 Esc 处理不看 `isComposing`)→ 包装层禁用 Radix 的 Esc,统一走 `useEscapeLayer`(已有输入法保护),且一次 Esc 只关一次、只关最上层。落点:Task 2 `Modal ignores Escape while composing and closes once otherwise`、`Escape closes only the modal when another layer is open beneath it`。
2. **投屏(全屏)时打开积分榜 / 冲突对话框看不见**:Radix 默认挂到 `document.body`,全屏时只有全屏元素的子树可见,对话框不可见却抢走焦点,老师在全班面前卡住 → 弹层挂进当前全屏元素。落点:Task 2 `Modal portals into the fullscreen element while presenting`。
3. **深色模式或投影仪上状态色看不清**:请假 / 缺勤 / 迟到的文字和浅底徽章在某一套主题里对比度不足 → 令牌数值经计算,浅深两套的正文、弱化文字、状态色(含 10% 浅底)对比度全部 ≥ 4.5,焦点环 ≥ 3。落点:Task 1 `contrast.test.ts`。
4. **平板竖屏 / 手机宽度下页面挤爆**:768 宽时概况栏把教室挤成一条,375 宽时顶栏和表单横向溢出 → 1100px 以下概况栏改为舞台上的浮层(可 Esc 关闭),顶栏 <768 收进菜单抽屉,登录 / 偏好 / 教室页在 375 宽无横向滚动。落点:Task 11 `renders the rail as an overlay below 1100px and closes it with Escape`、Task 5 `menu button opens the actions in a panel and closes on navigation`、Task 17 `no horizontal scroll at 375px`。
5. **只用键盘(或一体机外接键盘)的老师找不到焦点**:原来大部分按钮没有可见焦点,模式条只能 Tab 逐个走,关掉档案后焦点丢到页面顶部 → 全局 `:focus-visible` 焦点环、模式条和档案标签支持方向键、弹层关闭后焦点回到打开它的元素、`跳到主要内容` 链接。落点:Task 3 `arrow keys move focus without activating`、Task 2 `SidePanel restores focus to the opener on close`、Task 17 `keyboard focus is visible` / `skip link moves focus to main content`。

另有 M2a 计划"未在 M2a 做的"里的 **Drawer 焦点陷阱**(PR #3 遗留)在本计划顺带解决:学生档案改用 `SidePanel`(Radix Dialog 自带焦点陷阱)。

const HEX = String.raw`${PREFIX}-\[#[0-9a-fA-F]{3,8}\]`
// 前后必须是类名边界:空白、引号、反引号、`${`、`}` 或行首行尾
const RE = new RegExp(String.raw`(?<=^|[\s'"\`{}])(?:${HEX}|${PALETTE}|${MONO}|${LEGACY})(?=$|[\s'"\`}])`, 'gm')

async function signIn(page: Page) {
  await page.goto('/login')
  await page.getByLabel('登录名').fill('teacher01')
  await page.getByLabel('密码').fill('dev123')

}

test('theme choice persists across reload without a flash', async ({ page }) => {
  await page.goto('/login')
  await page.evaluate(() => localStorage.removeItem('ws-theme'))
  await page.reload()
  const toggle = page.getByRole('button', { name: /^主题:/ })
  while (!(await toggle.getAttribute('aria-label'))?.endsWith('深色')) await toggle.click()
  await expect(page.locator('html')).toHaveClass(/dark/)
  await page.reload()
  await expect(page.locator('html')).toHaveClass(/dark/)
  await page.evaluate(() => localStorage.removeItem('ws-theme'))
})

test('skip link moves focus to main content', async ({ page }) => {
  await signIn(page)
  await page.keyboard.press('Tab')
  await expect(page.getByRole('link', { name: '跳到主要内容' })).toBeFocused()
  await page.keyboard.press('Enter')
  await expect(page.getByRole('main')).toBeFocused()
})

test('keyboard focus is visible', async ({ page }) => {
  await page.goto('/login')
  await page.keyboard.press('Tab')
  const focused = page.locator(':focus')
  const ring = await focused.evaluate((el) => {
    const s = getComputedStyle(el)
    return s.outlineStyle !== 'none' || s.boxShadow !== 'none'
  })
  expect(ring).toBe(true)
})

for (const path of ['/login', '/teacher/classroom', '/teacher/preferences']) {
  test(`no horizontal scroll at 375px on ${path}`, async ({ page }) => {
    await page.setViewportSize({ width: 375, height: 812 })
    if (path !== '/login') await signIn(page)
    await page.goto(path)
    await page.waitForLoadState('networkidle')
    const overflow = await page.evaluate(() => document.documentElement.scrollWidth - document.documentElement.clientWidth)
    expect(overflow).toBeLessThanOrEqual(0)
  })
}

test('profile drawer traps focus and closes with Escape', async ({ page }) => {
  await signIn(page)
  await page.getByRole('button', { name: '王小一' }).click()

  await expect(drawer).toBeVisible()
  for (let i = 0; i < 12; i++) await page.keyboard.press('Tab')
  expect(await drawer.evaluate((d) => d.contains(document.activeElement))).toBe(true)

  await expect(drawer).toBeHidden()
})
