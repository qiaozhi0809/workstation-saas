## HTTP 契约(冻结)

```ts
interface Grading { pass_ratio: number; good_ratio: number }
type Stage = 'primary' | 'junior' | 'senior'
type SubjectCatalog = Record<Stage, SubjectFull[]>
interface Meta { version: string; school_name: string; school_tz: string }
type AckBlockReason = 'closed' | 'recalled' | 'readonly' | 'not_primary' | null
interface SetupItem { key: 'school' | 'year' | 'classes' | 'accounts' | 'assignments' | 'timetable' | 'cameras' | 'ai'; done: boolean; detail: string; to: string }
```

| 方法 | 路径 | 请求 | 响应 | 权限 / 说明 |
|---|---|---|---|---|
| GET | `/school/grading` | — | `Grading` | 任何已登录教职工与家长 |
| PUT | `/admin/settings/grading` | `Grading` | `Grading` | `settings.manage`;审计 |
| GET | `/school/subject-catalog` | — | `SubjectCatalog` | 任何已登录教职工 |
| PUT | `/admin/settings/subject-catalog` | `SubjectCatalog` | `SubjectCatalog` | `settings.manage`;审计 |
| POST | `/classes/{class_id}/subjects/fill-from-catalog` | — | `SubjectFull[]` | 该班 `exam.write`;把目录里该班没有的科目追加到末尾(已有的不改满分) |
| GET | `/meta` | — | `Meta` | 任何已登录用户(家长也可;解决 L74 校名、L79 时区) |
| GET / PUT | `/me/preferences` | 追加 `onboarded: {teacher?: string; parent?: string; admin?: string}`(ISO 时间) | 同 | PUT 只允许写当前用户拥有的语境 |
| GET | `/admin/setup-checklist` | — | `SetupItem[]` | `org.manage` 或 `settings.manage` |

- `InboxItem` 追加 `ack_block_reason: AckBlockReason`(`can_ack` 为假时给原因,为真时 `null`)与 `students[].class_name`(取 `notice_students.class_name`)。
- `CommentOut` 追加 `can_share: boolean`(调用者能否切换"给家长看";L70)。
- `ParentChild` 追加 `left_reason: 'graduated' | 'left' | null`(L77)。
- 联考表单的科目从 `GET /school/subject-catalog` 按年级学段取,后端 `GradeExamInput.subjects[].name` 必须在目录里,否则 400 `SUBJECT_NOT_IN_CATALOG`(L37)。
