## HTTP 契约(冻结)

> 后端段(Task 1–5)按此实现,前端段(Task 6–11)按此编写类型与 mock。**任何改动必须先改本节并通知其他段。** 路径前缀 `/api/v1`,错误外壳沿用 M1。下面用 TypeScript 记法描述 JSON;后端 pydantic 字段名逐一相同。

### 类型

```ts
type DeskSize = 1 | 2 | 3
type SeatLayoutMode = 'auto' | 'manual'
type SeatOrder = 'row' | 'col'
type LayoutHow = 'keep' | 'row' | 'col'

// GET /me/classes 的每一项:在已有字段后追加 6 个
interface ClassView {
  id: string; name: string; grade_name: string; seat_rows: number; seat_cols: number
  role: 'homeroom_teacher' | 'subject_teacher' | 'assistant_teacher'
  desk_size: DeskSize; seat_layout: SeatLayoutMode; seat_order: SeatOrder
  podium_left: number; podium_right: number   // 0..2
  room: string                                 // '' 表示没填
}

// GET /classes/{id}/classroom 追加
interface ClassroomSummary { /* 已有字段 */ school_name: string }

interface LayoutDraft {
  desk_size: DeskSize
  seat_layout: SeatLayoutMode
  rows: number            // 1..12;auto 时忽略
  cols: number | null     // 每排座位数;manual 必填且合规;auto 时作"尽量保持的每排座位数",null 或不合规 = 不保持
  podium_left: number     // 0..2
  podium_right: number    // 0..2
  how: LayoutHow
}
interface LayoutSave extends LayoutDraft { base_version: number; room: string }   // room 去首尾空格后 ≤ 30 字

interface LayoutPreview {
  rows: number; cols: number                       // 实际采用的行列(auto 时由后端算出)
  seats: { enrollment_id: string; row: number; col: number }[]   // 有座位的同学,含讲台边
  capacity: number                                 // rows × cols + podium_left + podium_right
  students: number                                 // 在读学生总数
  unseated: number                                 // 排完仍没座位的人数
}
interface LayoutSaved { version: number; moved: boolean; rows: number; cols: number }

// 学生表单(POST / PUT /classes/{id}/students...)的 StudentInput 追加
interface StudentInput { /* 已有字段 */ seat: { row: number; col: number } | null; auto_seat?: boolean }
```

`cols` 的合规范围(每排座位数):单人 `2..12`;双人 `2..12` 且为 2 的倍数;三人 `3..12` 且为 3 的倍数。

### 端点

| 方法 | 路径 | 权限 | 请求 | 响应 | 说明 |
|---|---|---|---|---|---|
| POST | `/classes/{id}/layout/preview` | `seating.write` | `LayoutDraft` | 200 `LayoutPreview` | 只读,不写审计;`fill_all = true` 时的结果(与保存一致) |
| PUT | `/classes/{id}/layout` | `seating.write` | `LayoutSave` | 200 `LayoutSaved` | 见"保存规则";写审计 `class.layout` |
| PUT | `/classes/{id}/seating` | `seating.write`(已有) | `SeatingSave`(已有) | 已有 | **改**:`seats[].row` 允许 0;`rows` / `cols` 必须等于班级当前值 |
| POST | `/classes/{id}/students` | 已有 | `StudentInput` | 已有 | **改**:`seat` 可以是讲台边座位;`auto_seat` 见"名单联动" |
| PUT | `/classes/{id}/students/{eid}` | 已有 | `StudentInput` | 已有 | **改**:`seat` 可以是讲台边座位;忽略 `auto_seat` |

### 错误码(新增 reason;外壳沿用 `SEAT_INVALID` 400)

| `details.reason` | 何时 |
|---|---|
| `layout_mismatch` | `PUT /seating` 的 `rows` / `cols` 与班级当前值不同 |
| `podium_unavailable` | 座位是 `row = 0`,但 `abs(col)` 超过那一侧的讲台桌数,或 `col = 0`,或 `abs(col) > 2` |
| `out_of_grid` | 已有;普通座位超出行列 |

请求体字段越界(`desk_size = 4`、`podium_left = 3`、`rows = 13`、manual 下 `cols` 不合规、`room` 31 字)走 M1 的校验外壳:400 `BAD_REQUEST`。保存时 `base_version` 不是当前版本 → 409 `SEAT_VERSION_CONFLICT`(同排座保存,`details.current_version`)。

### 保存规则

1. 按 `LayoutDraft` 定出新网格:auto → `auto_grid(需要排进普通座位的人数, desk_size, cols)`;manual → `rows` / `cols` 原样。
2. 用 `arrange(how, fill_all=True)` 算每个人的新座位与固定状态。
3. `moved` = 网格(行、列、桌型、讲台两侧桌数)有变化,**或**任何一人的座位变了,**或** `how ≠ 'keep'`。
4. `moved` 时:写班级 6 列与行列、`how ∈ {row, col}` 时把 `seat_order` 改成 `how`、版本号 +1、先清空全班座位再逐个写入、写快照;否则只写 `room` 与 `seat_layout`,版本号不变。
5. 无论 `moved` 与否都校验 `base_version`、都写审计 `class.layout`(`extra = {desk_size, seat_layout, rows, cols, podium_left, podium_right, how, moved}`)。

### 名单联动

- **自动增减排**(`seat_layout = 'auto'` 才做):新增学生、批量导入、删除学生之后,按新人数调用 `auto_grid(需要排进普通座位的人数, desk_size, 当前 seat_cols)`;行列变了就用 `arrange('keep', fill_all=False)` 重排(已坐好的不动、放不下的挪空位、没座位的保持没座位),写回行列、版本号 +1、写快照。
- **新增学生 `auto_seat = true` 且 `seat = null`**:先自动增减排,再按班级 `seat_order` 找第一个空的普通座位;没有空位就保持未排座。
- **批量导入**:先全部建好,再自动增减排,最后(`auto_seat = true` 时)按 `seat_order` 给新同学逐个找空位。
- "需要排进普通座位的人数" = 在读人数 − 坐在讲台边(且那张桌子仍存在)的人数。
- 找空位、自动增减排、按学号重排**都不会**把人放到讲台边座位。

`auto_grid`(照原版,换算成"每排座位数";不由签名决定,照抄这段):

```python
def auto_grid(n, desk, pref_cols):
    lo, hi = col_range(desk)
    def rows_for(c): return max(AUTO_ROWS[0], ceil(n / c))
    if n == 0:
        return 6, (pref_cols if cols_ok(pref_cols, desk) else default_cols(desk))
    if cols_ok(pref_cols, desk) and ceil(n / pref_cols) <= AUTO_ROWS[1]:
        return rows_for(pref_cols), pref_cols
    best = None
    for c in range(lo, hi + 1):
        if c % desk:
            continue
        r = rows_for(c)
        if r > AUTO_ROWS[1]:
            continue
        # 空座少(人少时最少 4 排,这部分空位不算浪费)、排数接近 6、每排接近 8 个座位
        score = (r * c - max(n, AUTO_ROWS[0] * c)) * 0.5 + abs(r - 6) * 2 + abs(c - 8) * 1.5
        if best is None or score < best[0]:
            best = (score, r, c)
    return (best[1], best[2]) if best else (AUTO_ROWS[1], hi)
```

`student_no_key`:学号为空排最后;学号按"数字段按数值、其余段按字符"逐段比较(`re.split(r"(\d+)", no)`,数字段转 `int`);相同再按姓名字符顺序。

`arrange`(不由签名决定,规则如下;返回**每个** sitter 的 `Placement`):

1. `keys = seat_keys(g, order if how == "keep" else how)`;`pods = set(podium_seats(g))`;`taken: set[Seat] = set()`。
2. **讲台边**:座位在 `pods` 里的同学(同一座位只认第一个)原样保留(`locked` 不变),计入 `taken`。
3. **固定**:`locked` 且座位在 `keys` 里、尚未被占的同学原样保留,计入 `taken`。
4. 其余为 `rest`(保持输入顺序)。
5. `how ∈ {"row","col"}`:`free = [k for k in keys if k not in taken]`;`rest` 按 `student_no_key` 排序后依次取 `free[i]`,取完的为 `None`;`locked = False`。
6. `how == "keep"`:座位在 `keys` 里且未被占的保留(`locked` 不变)并计入 `taken`;有座位但不合规(或被占)的进 `over`;没座位的进 `none`。`over` 按原座位 `(row, col)` 升序;`fill_all` 时 `over += sorted(none, key=student_no_key)`;`over` 依次取剩下的空位,取完的为 `None`,`locked = False`;`fill_all` 为假时 `none` 全部 `Placement(None, False)`。

`first_empty`:按 `seat_keys(g, order)` 找第一个不在 `occupied`、也不等于 `exclude` 的普通座位。
