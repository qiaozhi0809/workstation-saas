# M2b 成绩 · 范围清单

> 本文件逐项记录原版成绩录入、成绩分析、学生名单 / 导入导出(PRD `reference-html/features-extracted.md` §1.4、§1.9、§1.10、§3.6、§4、§6、§7、§8、§15)以及教室页里留给 M2b 的条目在新项目里的处理方式。
> 实施计划见 [`2026-11-02-M2b-成绩.md`](2026-11-02-M2b-成绩.md)。

## 用户拍板(2026-11-02)

1. **不精简,先复刻原版**:成绩录入、成绩分析、学生名单 / 档案编辑 / 删除 / 批量导入 / 导出全部对齐原版行为;画面与交互由新项目重做(spec D05)。只有依赖 AI 的两个按钮("AI 写分析报告"、"给退步同学家长写沟通消息")移到 M2c。
2. **成绩权限**:班主任建 / 改 / 删本班任何考试、录全部科目、看全部科目和总分排名、导出;**任课老师可以建只含自己科目的考试(单科小测),只能改 / 删自己建的;只录、只看本科目**(分析页只有本科目的指标、图表和按本科目算的排名,看不到总分和其他科目);不能导出。校领导 / 年级组长后端先给只读与导出权限,页面在 M3。
3. **副班主任**:M2b 不给任何成绩权限,也不碰这个身份;是否从产品里去掉留到 M3 账号与组织架构时再定。
4. **只做班级考试**:每场考试属于一个班;排名只算班内、读取时现算,不存库。年级联考与年级排名放 M3,表结构不挡路。
5. **学生这块按原版来**:名单页、添加 / 编辑表单(含座位、两组联系人、住校、其他备注)、删除、批量导入、导出都对齐原版。
6. **图表用 Recharts**(经 `npx shadcn@2.3.0 add chart` 引入,锁 2.x):用户批准的新增依赖。
7. **科目与满分**:每班一份"常用科目与满分",第一次按年级名推断学段套原版预设;建考试时新加的科目写回本班列表;及格线 = 满分 60%、优秀线 = 满分 85%,固定。
8. **"从下往上排座"删除**:来源不明,用户也没有这个需求;以后有具体需求再加。

## 逐项清单

标记:**对标** = 行为与原版一致(画面自绘 / 用新组件);**改** = 行为按 B 端需要调整;**新增** = 原版没有;**后移** = 依赖后续里程碑;**删除** = 不做。

### A. 考试与科目

| # | 原版功能 | 处理 | 说明 |
|---|---|---|---|
| A1 | 考试列表(名称 + 类型 + 日期 + 科目数 + 已录进度条) | 对标 | 新→旧;任课老师只看到含本科目的考试,进度只按本科目算 |
| A2 | 新建 / 编辑考试:名称、日期、类型(月考/期中/期末/周测/单元测/模拟考/其他)、科目与满分 chips、加新科目 | 对标 | 新科目写回本班科目列表;任课老师只能选本科目 |
| A3 | 删除考试连带清空分数 | 对标 + 改 | 二次确认;写审计;任课老师只能删自己建的 |
| A4 | 设置里的科目列表 + 学段预设(小学 5 科 / 初中 9 科 / 高中 9 科) | 改 | 每班一份,首次按年级名推断学段(含"高"→高中;含"初"或七/八/九→初中;一至六年级→小学;其余按初中) |
| A5 | 编辑考试时去掉某科 | 改 | 该科已录分数一并删除;把满分改得比已录分数低 → 400,提示是哪一科 |

### B. 成绩录入

| # | 原版功能 | 处理 | 说明 |
|---|---|---|---|
| B1 | 分数表格(学号 / 姓名 / 各科 / 总分 / 排名),输入框 `inputmode=decimal` | 对标 | 总分、排名、已录进度随输入即时刷新 |
| B2 | `parseScore`:全角转半角、去空格;`缺/缺考/-/—/\/x/X` = 缺考;空 = 清空 | 对标 | 最多 1 位小数,超出时提示格式错误 |
| B3 | 单元格样式:缺考 / 超出满分或负数 / 不及格 | 对标 | 超出满分的值**不保存**,格子标红并提示(原版存下了;新系统服务端校验 0 ≤ 分 ≤ 满分) |
| B4 | 键盘:Enter / ↓ 下一行,Shift+Enter / ↑ 上一行,光标在末尾 → 右一列,在开头 ← 左一列,聚焦全选 | 对标 | 兼容中文输入法(组合输入中不响应 Enter) |
| B5 | 从 Excel 粘贴整块(Tab / 换行),保留空行防错位,从当前格向右下填 | 对标 | 提示"已粘贴 N 格";超出满分的格子不保存并提示个数 |
| B6 | 每次输入立即保存 | 对标 + 改 | 改动先显示,0.6 秒内的改动合并成一次请求;状态显示"保存中… / 已保存 / 保存失败,重试";离开页面时有未保存的改动先提醒 |
| B7 | 按表头导入:第一行表头;姓名或学号列;科目列名严格等于考试科目;学号优先、重名不猜 | 对标 | 实时预览识别到几行、匹配几人、哪些科目;导入后提示"X 行没对上名字" |
| B8 | 导出 CSV:学号、姓名、各科、总分、排名;缺考写"缺考" | 对标 | 文件名 `<班级>-<考试>-成绩.csv`;BOM + 公式注入防护;仅班主任;写审计 |
| B9 | 两位老师同时录同一场考试 | 新增 | 按单元格保存,后写的覆盖先写的;任课老师只能写本科目,互不干扰 |
