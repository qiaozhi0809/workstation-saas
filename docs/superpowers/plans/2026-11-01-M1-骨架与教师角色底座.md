> **For AI agents / developers:** 本 plan 按 TDD 粒度拆成 19 个 task,每个 task 独立可测试、独立可提交。

> - 具体工具/技能依赖你所在的代理平台(Claude Code 用 `superpowers:subagent-driven-development`、`superpowers:executing-plans`;其他代理按同等原则)。

>
> **开始前先读 [`../../../AGENTS.md`](../../../AGENTS.md) 和 [`../specs/2026-11-01-三角色协作平台-design.md`](../specs/2026-11-01-三角色协作平台-design.md)。**

**Goal:** 搭起 workstation-saas 新项目的技术骨架,并实现"**教师可登录、看自己班的静态教室、点开学生档案**"这一最小闭环。

**Architecture:** 单体 Go 后端(Gin + sqlc + PostgreSQL + Redis)+ 单一 React SPA(Vite + TS + Tailwind + shadcn/ui + TanStack Query + React Router v7)。前后端通过 REST + JWT 通信。本阶段不含交互式教室模式(考勤/点评/排座)、不含监控、不含 AI、不含管理端和家长端。

**Tech Stack:**
- Backend: Go 1.22+, Gin, sqlc, pgx/v5, PostgreSQL 16, bcrypt, go-jose(JWT), zerolog, Viper
- Frontend: Node 20+, React 18, TypeScript 5, Vite 5, Tailwind CSS 3, shadcn/ui, TanStack Query v5, Zustand, React Router v7, hls.js(预留)
- Dev: Docker Compose(postgres + redis),Air(Go 热重载,可选)

**Spec:** [`docs/superpowers/specs/2026-11-01-三角色协作平台-design.md`](../specs/2026-11-01-三角色协作平台-design.md)

**考古参考:** [`reference-html/features-extracted.md`](../../../reference-html/features-extracted.md) — 原 HTML 的功能提取,新项目 UI/业务规则的权威参考。

## Global Constraints

- **语言 & 版本**:Backend Go ≥ 1.22、Frontend Node ≥ 20、PostgreSQL ≥ 16、Redis ≥ 7。
- **代码库布局**:本 plan 的根目录为**本仓库 git 根**(本地路径 `E:/教学工作台/`,远端私有仓库 `qiaozhi0809/workstation-saas`);原 HTML 项目作为 `reference-html/` 子目录,只读参考。
- **目录结构**遵循 spec §4.3。
- **数据库命名**:表名**蛇形复数**(`users`, `classes`, `enrollments`);字段**蛇形**(`academic_year_id`);**所有表自带** `id uuid primary key default gen_random_uuid()`、`created_at timestamptz not null default now()`、`updated_at timestamptz not null default now()`,触发器自动更新 `updated_at`。
- **ID 类型**:全部 **UUID v4**;API 用字符串传输。
- **时区**:数据库 `timestamptz`;后端业务逻辑用 `time.Time` UTC;前端渲染时按学校时区展示(学校时区默认 `Asia/Shanghai`,存 `schools.timezone`)。
- **错误响应**:统一结构 `{ "error": { "code": "SNAKE_UPPER", "message": "...", "details"?: {...} } }`;HTTP 状态码符合 REST 语义。
- **分页**:列表接口统一 `?cursor=<base64>&limit=<n>`,默认 limit=50、max=200;响应 `{ "items": [...], "next_cursor": "..." | null }`。
- **提交规范**:[Conventional Commits](https://www.conventionalcommits.org/) — `feat:`, `fix:`, `chore:`, `test:`, `docs:`, `refactor:`。每个 task 结束至少一次 commit。
- **测试**:后端 `go test ./...`,前端 `vitest run`;**TDD 要求**:每个新函数/组件先写失败测试再实现。
- **Lint & Format**:后端 `gofmt` + `golangci-lint`;前端 ESLint + Prettier。
- **禁止**:不写 ORM 层以上的"通用抽象"(repository 直接是 sqlc 生成 + 一个 service 组合),不写 interface mock(用真 Postgres via testcontainers 做集成测试)。
## Review Focus

本 plan 的任务测试了基础 CRUD + 认证 + 权限 + 静态教室渲染,但 spec 隐含的一些**跨任务输入类/失败模式**不被任何单任务独自测到。以下五条**最可能咬到真实用户**,把每条的测试落到对应任务的测试步骤里:

1. **过期的 access token 被用来访问受保护接口** → **期望**:401,前端自动走 refresh 流;refresh 也过期则跳转登录。**测试落点**:Task 5 Step 添加 "过期 token → 401" 的后端测试;Task 14 Step 添加 "拦截 401 自动 refresh 一次" 的前端 unit test。
2. **班主任请求查看别的班级的学生列表** → **期望**:403,审计记录尝试。**测试落点**:Task 10 Step 添加 "班主任越权请求 → 403 + AuditLog 中有一条 denied 记录"。
3. **学生没有家庭信息(父母字段为 NULL)时请求学生档案详情** → **期望**:字段按 role 过滤后不出现 "null" 字样,前端渲染为"暂无"占位。**测试落点**:Task 10 Step 添加 "空家庭信息 → DTO 中省略而非 null" 的后端测试;Task 18 Step 添加 "DTO 字段缺失时 UI 渲染占位" 的前端测试。
4. **用户同时持有班主任 + 其他班任课老师**(多 RoleBinding) → **期望**:两个班的教室切换可见;其他班的学生档案只看到有限字段。**测试落点**:Task 10 Step 加 "同一 user 双 RoleBinding 的字段级可见测试";Task 15 Step 加 "shell 内班级切换下拉显示两个班"。
5. **登录名含中文或空格,密码含 Unicode(如 emoji 或中文)** → **期望**:登录名 trim 后仍有效、密码 bcrypt 正常验证。**测试落点**:Task 4 Step 加 "unicode 密码 bcrypt 往返测试";Task 14 Step 加 "login 表单输入含空格/中文的往返测试"。

- [ ] **Step 2: 写 schema 迁移 001_init.up.sql(主要表)**

`server/migrations/001_init.up.sql`:
```sql
CREATE EXTENSION IF NOT EXISTS "pgcrypto";

-- 通用 trigger: 自动维护 updated_at
CREATE OR REPLACE FUNCTION trg_touch_updated_at() RETURNS trigger AS $$
BEGIN NEW.updated_at = now(); RETURN NEW; END;
$$ LANGUAGE plpgsql;

CREATE TABLE schools (
  id uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  name text NOT NULL,
  address text,
  logo_url text,
  timezone text NOT NULL DEFAULT 'Asia/Shanghai',
  locale text NOT NULL DEFAULT 'zh-CN',
  created_at timestamptz NOT NULL DEFAULT now(),
  updated_at timestamptz NOT NULL DEFAULT now()
);
CREATE TRIGGER schools_touch BEFORE UPDATE ON schools
  FOR EACH ROW EXECUTE FUNCTION trg_touch_updated_at();

CREATE TABLE academic_years (
  id uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  school_id uuid NOT NULL REFERENCES schools(id) ON DELETE CASCADE,
  name text NOT NULL,
  start_date date NOT NULL,
  end_date date NOT NULL,
  is_active boolean NOT NULL DEFAULT false,
  created_at timestamptz NOT NULL DEFAULT now(),
  updated_at timestamptz NOT NULL DEFAULT now(),
  UNIQUE (school_id, name)
);
CREATE TRIGGER academic_years_touch BEFORE UPDATE ON academic_years
  FOR EACH ROW EXECUTE FUNCTION trg_touch_updated_at();
CREATE UNIQUE INDEX academic_years_one_active
  ON academic_years (school_id) WHERE is_active;

CREATE TABLE grades (
  id uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  school_id uuid NOT NULL REFERENCES schools(id) ON DELETE CASCADE,
  academic_year_id uuid NOT NULL REFERENCES academic_years(id) ON DELETE CASCADE,
  name text NOT NULL,
  display_order int NOT NULL DEFAULT 0,
  created_at timestamptz NOT NULL DEFAULT now(),
  updated_at timestamptz NOT NULL DEFAULT now()
);
CREATE TRIGGER grades_touch BEFORE UPDATE ON grades
  FOR EACH ROW EXECUTE FUNCTION trg_touch_updated_at();

CREATE TABLE classes (
  id uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  school_id uuid NOT NULL REFERENCES schools(id) ON DELETE CASCADE,
  academic_year_id uuid NOT NULL REFERENCES academic_years(id) ON DELETE CASCADE,
  grade_id uuid NOT NULL REFERENCES grades(id) ON DELETE CASCADE,
  name text NOT NULL,
  seat_rows int NOT NULL DEFAULT 7,
  seat_cols int NOT NULL DEFAULT 4,
  homeroom_teacher_id uuid,
  active boolean NOT NULL DEFAULT true,
  created_at timestamptz NOT NULL DEFAULT now(),
  updated_at timestamptz NOT NULL DEFAULT now()
);
CREATE TRIGGER classes_touch BEFORE UPDATE ON classes
  FOR EACH ROW EXECUTE FUNCTION trg_touch_updated_at();
CREATE INDEX classes_school_year ON classes (school_id, academic_year_id);

CREATE TABLE users (
  id uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  school_id uuid NOT NULL REFERENCES schools(id) ON DELETE CASCADE,
```

```go
func MigrateUp(dsn, migrationsDir string) error {
```

```go
package auth

import "golang.org/x/crypto/bcrypt"

func HashPassword(plain string) (string, error) {
    b, err := bcrypt.GenerateFromPassword([]byte(plain), 10)
    return string(b), err
}

func CheckPassword(hash, plain string) error {
    return bcrypt.CompareHashAndPassword([]byte(hash), []byte(plain))
}
```

```go
    "context"; "errors"; "time"

    "github.com/jackc/pgx/v5"
    "github.com/jackc/pgx/v5/pgxpool"

type Repo interface {
    GetByLoginName(ctx context.Context, schoolID uuid.UUID, loginName string) (*User, error)
    GetByID(ctx context.Context, id uuid.UUID) (*User, error)
    UpdateLastLogin(ctx context.Context, id uuid.UUID, at time.Time) error
    Create(ctx context.Context, u *User) error
}

type repo struct{ pool *pgxpool.Pool }
func NewRepo(p *pgxpool.Pool) Repo { return &repo{p} }

const selectCols = `id, school_id, login_name, password_hash, display_name, status, last_login_at, created_at, updated_at`

func scanOne(row pgx.Row) (*User, error) {
    var u User
    err := row.Scan(&u.ID, &u.SchoolID, &u.LoginName, &u.PasswordHash, &u.DisplayName, &u.Status, &u.LastLoginAt, &u.CreatedAt, &u.UpdatedAt)
    if errors.Is(err, pgx.ErrNoRows) { return nil, nil }
    if err != nil { return nil, err }
    return &u, nil
}

func (r *repo) GetByLoginName(ctx context.Context, schoolID uuid.UUID, loginName string) (*User, error) {
    return scanOne(r.pool.QueryRow(ctx,
        `SELECT `+selectCols+` FROM users WHERE school_id=$1 AND login_name=$2`,
        schoolID, loginName))
}
func (r *repo) GetByID(ctx context.Context, id uuid.UUID) (*User, error) {
    return scanOne(r.pool.QueryRow(ctx,
        `SELECT `+selectCols+` FROM users WHERE id=$1`, id))
}
func (r *repo) UpdateLastLogin(ctx context.Context, id uuid.UUID, at time.Time) error {
    _, err := r.pool.Exec(ctx, `UPDATE users SET last_login_at=$1 WHERE id=$2`, at, id)
    return err
}
func (r *repo) Create(ctx context.Context, u *User) error {
    return r.pool.QueryRow(ctx,
        `INSERT INTO users (school_id, login_name, password_hash, display_name)
         VALUES ($1,$2,$3,$4) RETURNING id, created_at, updated_at`,
        u.SchoolID, u.LoginName, u.PasswordHash, u.DisplayName,
    ).Scan(&u.ID, &u.CreatedAt, &u.UpdatedAt)
```

```go
package auth

import (
    "errors"; "time"
    "github.com/golang-jwt/jwt/v5"
    "github.com/google/uuid"
)

type TokenKind string
const ( Access TokenKind = "access"; Refresh TokenKind = "refresh" )

var ErrTokenExpired = errors.New("token expired")
var ErrTokenInvalid = errors.New("token invalid")

type Signer struct {
    secret []byte
    accessTTL, refreshTTL time.Duration
}

func NewSigner(secret string, access, refresh time.Duration) *Signer {
    return &Signer{[]byte(secret), access, refresh}
}

type claims struct {
    jwt.RegisteredClaims
    Kind TokenKind `json:"kind"`
}

func (s *Signer) Sign(userID uuid.UUID, kind TokenKind) (string, time.Time, error) {
    ttl := s.accessTTL
    if kind == Refresh { ttl = s.refreshTTL }
    exp := time.Now().Add(ttl)
    c := claims{
        RegisteredClaims: jwt.RegisteredClaims{
            Subject: userID.String(),
            ExpiresAt: jwt.NewNumericDate(exp),
            IssuedAt:  jwt.NewNumericDate(time.Now()),
        },
        Kind: kind,
    }
    tok := jwt.NewWithClaims(jwt.SigningMethodHS256, c)
    str, err := tok.SignedString(s.secret)
    return str, exp, err
}

func (s *Signer) Verify(tokenStr string, want TokenKind) (uuid.UUID, error) {
    tok, err := jwt.ParseWithClaims(tokenStr, &claims{}, func(t *jwt.Token) (any, error) {
        return s.secret, nil
    })
    if err != nil {
        if errors.Is(err, jwt.ErrTokenExpired) { return uuid.Nil, ErrTokenExpired }
        return uuid.Nil, ErrTokenInvalid
    }
    c, ok := tok.Claims.(*claims)
    if !ok || !tok.Valid { return uuid.Nil, ErrTokenInvalid }
    if c.Kind != want { return uuid.Nil, ErrTokenInvalid }
    return uuid.Parse(c.Subject)
}
```

```go
import (
    "context"; "errors"; "time"
    "github.com/google/uuid"
    "github.com/qiaozhi0809/workstation-saas/server/internal/domain/user"

var ErrInvalidCredentials = errors.New("invalid credentials")

type Service struct {
    users  user.Repo
    signer *Signer
}
func NewService(u user.Repo, s *Signer) *Service { return &Service{u, s} }

type LoginResult struct {
    AccessToken, RefreshToken string
    AccessExpiresAt time.Time
    User *user.User
}

func (s *Service) Login(ctx context.Context, schoolID uuid.UUID, loginName, plainPw string) (*LoginResult, error) {
    u, err := s.users.GetByLoginName(ctx, schoolID, loginName)
    if err != nil { return nil, err }
    if u == nil || u.Status != "active" { return nil, ErrInvalidCredentials }
    if err := CheckPassword(u.PasswordHash, plainPw); err != nil { return nil, ErrInvalidCredentials }
    at, aExp, err := s.signer.Sign(u.ID, Access);  if err != nil { return nil, err }
    rt, _,    err := s.signer.Sign(u.ID, Refresh); if err != nil { return nil, err }
    _ = s.users.UpdateLastLogin(ctx, u.ID, time.Now())
    return &LoginResult{AccessToken: at, RefreshToken: rt, AccessExpiresAt: aExp, User: u}, nil
}

func (s *Service) Refresh(ctx context.Context, refresh string) (string, time.Time, error) {
    uid, err := s.signer.Verify(refresh, Refresh)
    if err != nil { return "", time.Time{}, err }
    u, err := s.users.GetByID(ctx, uid)
    if err != nil || u == nil || u.Status != "active" {
        return "", time.Time{}, ErrInvalidCredentials
    }
    return s.signer.Sign(uid, Access)
}
```

```go
package auth

import (
    "errors"; "strings"
    "github.com/gin-gonic/gin"
    "github.com/qiaozhi0809/workstation-saas/server/internal/domain/user"
)

const CtxUserKey = "ctx_user"

func Middleware(s *Signer, users user.Repo) gin.HandlerFunc {
    return func(c *gin.Context) {
        h := c.GetHeader("Authorization")
        if !strings.HasPrefix(h, "Bearer ") {
            c.AbortWithStatusJSON(401, gin.H{"error": gin.H{"code":"UNAUTHORIZED","message":"missing bearer token"}}); return
        }
        tok := strings.TrimPrefix(h, "Bearer ")
        uid, err := s.Verify(tok, Access)
        if err != nil {
            code := "UNAUTHORIZED"; if errors.Is(err, ErrTokenExpired) { code = "TOKEN_EXPIRED" }
            c.AbortWithStatusJSON(401, gin.H{"error": gin.H{"code":code,"message":err.Error()}}); return
        }
        u, err := users.GetByID(c.Request.Context(), uid)
        if err != nil || u == nil || u.Status != "active" {
            c.AbortWithStatusJSON(401, gin.H{"error": gin.H{"code":"UNAUTHORIZED","message":"user not found"}}); return
        }
        c.Set(CtxUserKey, u)
        c.Next()
    }
}

func CurrentUser(c *gin.Context) *user.User {
    v, _ := c.Get(CtxUserKey); u, _ := v.(*user.User); return u
}
```

```go
    SchoolID string `json:"school_id" binding:"required,uuid"`

    Password string `json:"password" binding:"required"`

func (h *AuthHandler) Login(c *gin.Context) {
    var req loginReq
    if err := c.ShouldBindJSON(&req); err != nil { httpx.Fail(c, 400, "BAD_REQUEST", err.Error()); return }
    sid, _ := uuid.Parse(req.SchoolID)
    res, err := h.Svc.Login(c.Request.Context(), sid, req.LoginName, req.Password)
    if err != nil { httpx.Fail(c, 401, "INVALID_CREDENTIALS", "login name or password incorrect"); return }
    c.JSON(200, gin.H{
        "access_token": res.AccessToken,
        "refresh_token": res.RefreshToken,
        "expires_at": res.AccessExpiresAt,
        "user": gin.H{ "id": res.User.ID, "display_name": res.User.DisplayName },

    if err != nil { httpx.Fail(c, 401, "INVALID_REFRESH", err.Error()); return }

}
```

```go
package rbac

import (
    "context"; "encoding/json"
    "github.com/google/uuid"
    "github.com/jackc/pgx/v5/pgxpool"
)

type Scope struct {
    SchoolID, GradeID, ClassID uuid.UUID
    Subject *string
}

type Binding struct {
    Role Role
    Scope Scope
    AcademicYearID uuid.UUID
}

func LoadBindings(ctx context.Context, pool *pgxpool.Pool, userID uuid.UUID) ([]Binding, error) {
    rows, err := pool.Query(ctx,
        `SELECT role_type, scope, academic_year_id FROM role_bindings
         WHERE user_id=$1 AND ended_at IS NULL`, userID)
    if err != nil { return nil, err }
    defer rows.Close()
    var out []Binding
    for rows.Next() {
        var b Binding
        var scopeRaw []byte
        if err := rows.Scan(&b.Role, &scopeRaw, &b.AcademicYearID); err != nil { return nil, err }
        var s struct { ClassID, GradeID, SchoolID string; Subject *string }
        _ = json.Unmarshal(scopeRaw, &s)
        if s.ClassID != "" { b.Scope.ClassID, _ = uuid.Parse(s.ClassID) }
        if s.GradeID != "" { b.Scope.GradeID, _ = uuid.Parse(s.GradeID) }
        if s.SchoolID != "" { b.Scope.SchoolID, _ = uuid.Parse(s.SchoolID) }
        b.Scope.Subject = s.Subject
        out = append(out, b)
    }
    return out, nil
}

// Can 判定:binding 中有角色允许该 perm,且作用域覆盖 target。
func Can(bindings []Binding, perm Perm, target Scope) bool {
    for _, b := range bindings {
        if !hasPerm(b.Role, perm) { continue }
        if !scopeCovers(b.Scope, target) { continue }
        return true
    }
    return false
}

func hasPerm(r Role, p Perm) bool {
    for _, x := range rolePerms[r] { if x == p { return true } }
    return false
}

// scopeCovers:绑定作用域是否覆盖目标。
// 规则:绑定里的 ClassID 若非 nil,只匹配同班;若 nil 则看 GradeID;再看 SchoolID。
func scopeCovers(b, target Scope) bool {
    if b.ClassID != uuid.Nil { return b.ClassID == target.ClassID }
    if b.GradeID != uuid.Nil { return b.GradeID == target.GradeID }
    if b.SchoolID != uuid.Nil { return b.SchoolID == target.SchoolID }
    return false
}
```

```go
package rbac

import (
    "github.com/gin-gonic/gin"
    "github.com/jackc/pgx/v5/pgxpool"
    "github.com/qiaozhi0809/workstation-saas/server/internal/auth"
    httpx "github.com/qiaozhi0809/workstation-saas/server/internal/http"
)

const CtxBindingsKey = "ctx_bindings"

// Loader:登录后挂 bindings 到 ctx。
func Loader(pool *pgxpool.Pool) gin.HandlerFunc {
    return func(c *gin.Context) {
        u := auth.CurrentUser(c)
        if u == nil { c.Next(); return }
        bs, err := LoadBindings(c.Request.Context(), pool, u.ID)
        if err != nil { httpx.Fail(c, 500, "RBAC_LOAD", err.Error()); return }
        c.Set(CtxBindingsKey, bs)
        c.Next()
    }
}

func Current(c *gin.Context) []Binding {
    v, _ := c.Get(CtxBindingsKey); bs, _ := v.([]Binding); return bs
}

func RequirePerm(perm Perm, scope func(c *gin.Context) Scope) gin.HandlerFunc {
    return func(c *gin.Context) {
        if !Can(Current(c), perm, scope(c)) {
            httpx.Fail(c, 403, "FORBIDDEN", "permission denied"); return
        }
        c.Next()
    }
}
```

```go
func (s *Service) ListForUser(ctx context.Context, bindings []rbac.Binding, yearID uuid.UUID) ([]ClassView, error) {
    classIDs := make(map[uuid.UUID]rbac.Role)
    for _, b := range bindings {
        if b.AcademicYearID != yearID { continue }
        if b.Scope.ClassID == uuid.Nil { continue }
        // 已经有(更高权限)绑定了,不覆盖
        if existing, ok := classIDs[b.Scope.ClassID]; ok {
            if roleRank(existing) >= roleRank(b.Role) { continue }
        }
        classIDs[b.Scope.ClassID] = b.Role
    }
    ids := make([]uuid.UUID, 0, len(classIDs))
    for id := range classIDs { ids = append(ids, id) }
    cs, err := s.repo.ListByIDs(ctx, ids)
    if err != nil { return nil, err }
    views := make([]ClassView, 0, len(cs))
    for _, c := range cs {
        views = append(views, ClassView{
            ID: c.ID, Name: c.Name, GradeName: c.GradeName,
            SeatRows: c.SeatRows, SeatCols: c.SeatCols,
            Role: string(classIDs[c.ID]),
        })
    }
    return views, nil
}

// roleRank:班主任 > 副班 > 任课,用于同班多绑定展示
func roleRank(r rbac.Role) int {
    switch r {
    case rbac.RoleHomeroomTeacher:  return 3
    case rbac.RoleAssistantTeacher: return 2
    case rbac.RoleSubjectTeacher:   return 1
    }
    return 0
}
```

```go
type StudentProfileDTO struct {
    ID uuid.UUID              `json:"id"`
    MK string                 `json:"mk"`

    StudentNo *string          `json:"student_no,omitempty"`

    AvatarSeed *string         `json:"avatar_seed,omitempty"`
    // 可选字段按权限才序列化
    FamilyStructure *string    `json:"family_structure,omitempty"`
    LearningSummary *string    `json:"learning_summary,omitempty"`
    Personality *string        `json:"personality,omitempty"`
    HealthNotes *string        `json:"health_notes,omitempty"`
    Tags []string              `json:"tags,omitempty"`

var ErrForbidden = errors.New("forbidden")

func (s *Service) ProfileFor(ctx context.Context, studentID uuid.UUID, bs []rbac.Binding, callerUserID uuid.UUID) (*StudentProfileDTO, error) {
    stu, enr, err := s.repo.GetWithEnrollment(ctx, studentID)   // JOIN students/enrollments
    if err != nil { return nil, err }
    if stu == nil { return nil, nil }
    target := rbac.Scope{ClassID: enr.ClassID}
    if !rbac.Can(bs, rbac.PermStudentReadBasic, target) {
        return nil, ErrForbidden
    }
    dto := &StudentProfileDTO{ID: stu.ID, MK: stu.MK, Name: stu.Name, ClassID: enr.ClassID}
    if stu.Gender != "" { g := stu.Gender; dto.Gender = &g }
    if stu.StudentNo != "" { n := stu.StudentNo; dto.StudentNo = &n }
    // ... 其他基本字段同理

    if rbac.Can(bs, rbac.PermStudentReadFamily, target) {
        if stu.FamilyStructure != "" { f := stu.FamilyStructure; dto.FamilyStructure = &f }
    }
    if rbac.Can(bs, rbac.PermStudentReadLearning, target) {
        if stu.LearningSummary != "" { l := stu.LearningSummary; dto.LearningSummary = &l }
    }
    if rbac.Can(bs, rbac.PermStudentReadHealth, target) {
        if stu.HealthNotes != "" { h := stu.HealthNotes; dto.HealthNotes = &h }
        if stu.Personality != "" { p := stu.Personality; dto.Personality = &p }
        dto.Tags = stu.Tags
    }
    if rbac.Can(bs, rbac.PermStudentReadTeacherNotes, target) {
        if raw := notesForAuthor(stu.TeacherNotes, callerUserID); raw != nil {
            dto.TeacherNotes = raw
        }
    }
    return dto, nil
}

// notesForAuthor:teacher_notes 是 jsonb 对象,key 是作者 user_id,只返回本人那条
func notesForAuthor(notes json.RawMessage, authorID uuid.UUID) json.RawMessage {
    if len(notes) == 0 { return nil }
    var m map[string]json.RawMessage
    if err := json.Unmarshal(notes, &m); err != nil { return nil }
    return m[authorID.String()]
}
```

```ts
// src/shared/api/client.ts
import { useAuthStore } from '@/shared/stores/auth'

const BASE = import.meta.env.VITE_API_BASE ?? 'http://localhost:8080'

export class ApiError extends Error {
  constructor(public status: number, public code: string, msg: string, public details?: unknown) { super(msg) }
}

async function raw(method: string, path: string, body?: unknown, token?: string | null): Promise<Response> {
  const headers: Record<string, string> = { 'Content-Type': 'application/json' }
  if (token) headers['Authorization'] = 'Bearer '+token
  return fetch(BASE+path, { method, headers, body: body ? JSON.stringify(body) : undefined })
}

export async function api<T>(method: string, path: string, body?: unknown): Promise<T> {
  const { accessToken, refreshToken, updateAccess, logout } = useAuthStore.getState()
  let res = await raw(method, path, body, accessToken)
  if (res.status === 401 && refreshToken) {
    const rr = await raw('POST', '/auth/refresh', { refresh_token: refreshToken })
    if (rr.ok) {
      const data = await rr.json(); updateAccess(data.access_token)
      res = await raw(method, path, body, data.access_token)
    } else {
      logout(); window.location.href = '/login'
      throw new ApiError(401, 'UNAUTHORIZED', 'session expired')
    }
  }
  if (!res.ok) {
    const err = (await res.json().catch(() => ({ error: {} }))).error ?? {}
    throw new ApiError(res.status, err.code ?? 'UNKNOWN', err.message ?? res.statusText, err.details)
  }
  return res.json() as Promise<T>
}
```

```ts
// src/shared/components/ClassroomMap/layout.ts
export interface LayoutInput { rows: number; cols: number; container: { w: number; h: number } }
export interface SeatPos { row: number; col: number; x: number; y: number }
export interface Layout { seatPositions: SeatPos[]; scale: number }

const PODIUM_H = 80

export function computeLayout(i: LayoutInput): Layout {
  const padX = 40, padY = 40
  const availW = i.container.w - padX*2
  const availH = i.container.h - padY*2 - PODIUM_H
  const cellW = availW / i.cols
  const cellH = availH / i.rows
  const positions: SeatPos[] = []
  for (let r = 0; r < i.rows; r++) {
    for (let c = 0; c < i.cols; c++) {
      positions.push({
        row: r+1, col: c+1,
        x: padX + cellW*(c + 0.5),
        y: padY + PODIUM_H + cellH*(r + 0.5),
      })
    }
  }
  return { seatPositions: positions, scale: 1 }
}
```

```tsx
// index.tsx
import { useRef, useState } from 'react'
import type { ClassroomMapProps } from './types'
import { computeLayout } from './layout'
import StudentSeatView from './StudentSeat'
import HoverCard from './HoverCard'

export default function ClassroomMap({ seats, rows, cols, mode='daily', onSeatClick }: ClassroomMapProps) {
  const [hover, setHover] = useState<{seat: any; x: number; y: number} | null>(null)
  const ref = useRef<HTMLDivElement>(null)

  // 简化版:容器固定大小 800×500;后续加 ResizeObserver
  const layout = computeLayout({ rows, cols, container: { w: 800, h: 500 } })
  const byPos = new Map(seats.map(s => [`${s.seat_row}-${s.seat_col}`, s]))

  return (
    <div ref={ref} className="relative mx-auto" style={{ width: 800, height: 500 }}>
      <svg width={800} height={500}>
        {/* 讲台 */}
        <rect x={320} y={20} width={160} height={48} rx={6} fill="#ffffff" stroke="#e2e2df"/>
        <text x={400} y={48} textAnchor="middle" fontSize={13} fill="#5c5c5a">讲 台</text>
        {/* 座位 */}
        {layout.seatPositions.map(p => {
          const seat = byPos.get(`${p.row}-${p.col}`)
          if (!seat) {
            return (
              <g key={`${p.row}-${p.col}`} transform={`translate(${p.x},${p.y})`}>
                <circle r={20} fill="none" stroke="#ececea" strokeDasharray="3 3"/>
              </g>
            )
          }
          return (
            <g key={seat.enrollment_id}
               onMouseEnter={() => setHover({ seat, x: p.x, y: p.y })}
               onMouseLeave={() => setHover(null)}>
              <StudentSeatView
                seat={seat} x={p.x} y={p.y}
                scale={mode==='mini' ? 0.5 : 1}
                onClick={() => onSeatClick?.(seat)}
              />
            </g>
          )
        })}
      </svg>
      {hover && (
        <div style={{ position: 'absolute', left: hover.x + 24, top: hover.y - 8 }}>
          <HoverCard seat={hover.seat} />
        </div>
      )}
    </div>
  )
}
```

```tsx
// src/roles/teacher/Classroom/ClassroomPage.tsx
import { useNavigate } from 'react-router-dom'
import { useQuery } from '@tanstack/react-query'
import { studentsApi } from '@/shared/api/students'
import { classesApi } from '@/shared/api/classes'
import { useTeacherStore } from '@/shared/stores/teacher'
import ClassroomMap from '@/shared/components/ClassroomMap'

export default function ClassroomPage() {
  const nav = useNavigate()
  const classId = useTeacherStore(s => s.classId)
  const { data: cls } = useQuery({
    queryKey: ['my-classes'], queryFn: () => classesApi.mine(),
    select: (d) => d.items.find(x => x.id === classId),
    enabled: !!classId,
  })
  const { data: students, isLoading } = useQuery({
    queryKey: ['class-students', classId],
    queryFn: () => studentsApi.listInClass(classId!),
    enabled: !!classId,
  })
  if (!classId) return <div className="p-6 text-ink-3">没有可查看的班级</div>
  if (isLoading) return <div className="p-6">加载中…</div>
  return (
    <div className="p-6">
      <h2 className="text-base font-semibold mb-4">{cls?.name ?? '教室'}</h2>
      <ClassroomMap
        rows={cls?.seat_rows ?? 6}
        cols={cls?.seat_cols ?? 4}
        seats={students?.items ?? []}
        mode="daily"
        onSeatClick={(seat) => nav(`/teacher/students/${seat.student_id}`)}
      />
    </div>
  )
}
```

```tsx
import { useQuery } from '@tanstack/react-query'
import { useNavigate, useParams } from 'react-router-dom'
import { studentsApi } from '@/shared/api/students'
```
