**Goal:** 搭起 workstation-saas 的技术骨架,并实现"**教师可登录、看自己班的静态教室、点开学生档案**"这一最小闭环。

**Architecture:** 单个 Python 后端(FastAPI 同步路由 + SQLAlchemy 2 同步 + Alembic + PostgreSQL + Redis)+ 单一 React SPA(Vite 5 + React 18 + TS + Tailwind 3 + TanStack Query + Zustand + React Router 7)。后端全部接口挂在 `/api/v1` 下;开发期前端经 Vite 代理访问后端,同源,无需 CORS。本阶段不含交互式教室模式、监控、AI、管理端和家长端。

**Tech Stack:**

- Frontend:Node 20、React 18.3、TypeScript 5、Vite 5.4、Tailwind 3.4、TanStack Query 5、Zustand 5、React Router 7;测试 Vitest 2 + Testing Library + Playwright
- Dev:Docker Compose(postgres + redis,带 healthcheck)

## Global Constraints

- **版本**:Python `>=3.12,<3.13`;Node ≥ 20;PostgreSQL 16;Redis 7;React 18;Vite 5;Tailwind 3。**不要用 `@latest` 安装前端脚手架或依赖**,一律按本 plan 给出的版本号。
- **代码库布局**:路径均相对仓库根目录。后端在 `server/`,前端在 `apps/web/`,开发编排在 `deploy/`。
- **API**:全部后端路由前缀 `/api/v1`。
- **数据库命名**:表名蛇形复数;字段蛇形;所有表 `id uuid primary key default gen_random_uuid()`;业务表带 `created_at` / `updated_at timestamptz`,触发器维护 `updated_at`。
- **ID**:UUID v4,API 以字符串传输。
- **时区**:数据库 `timestamptz`;后端一律 UTC aware `datetime`;前端按 `schools.timezone`(默认 `Asia/Shanghai`)展示。
- **错误响应**:统一 `{"error": {"code": "SNAKE_UPPER", "message": "...", "details"?: {...}}}`,HTTP 状态码符合 REST 语义。
- **分页**:列表接口统一 `?cursor=<base64>&limit=<n>`(默认 50、最大 200),响应 `{"items": [...], "next_cursor": ... | null}`。M1 唯一的列表是班级名单(≤ 60 人)和"我的班级",**不分页**,但响应仍用 `{"items": [...]}` 外壳。
- **数据库访问**:SQLAlchemy 2 **同步** API;路由函数用 `def` 不用 `async def`。写操作由执行写入的 service 函数显式 `db.commit()`,`get_db` 依赖只负责开关 Session。
- **测试**:后端 `cd server && uv run pytest`;前端 `cd apps/web && npm run test`。**不 mock 数据库和 Redis**,统一用 testcontainers。TDD:先写失败测试。
- **Lint**:后端 `uv run ruff check . && uv run ruff format --check .`;前端 `npm run lint`。
- **提交**:Conventional Commits;每个 task 结束至少一次 commit。
- **禁止**:不写 repository 抽象层(service 函数直接用 SQLAlchemy Session);不为 M1 用不到的表写 ORM 映射。

## Review Focus

以下五条是 spec 隐含、最可能咬到真实用户的输入/失败模式,每条的测试已落在对应 task:

1. **过期的 access token 访问受保护接口** → 401 `TOKEN_EXPIRED`;前端自动 refresh 一次并重试;refresh 失效则清空登录态跳 `/login`。落点:Task 5 `test_expired_token_returns_token_expired`、Task 11 `refreshes once on 401 and retries` / `clears session when refresh fails`。
2. **班主任请求别的班的名单或学生档案** → 403 `FORBIDDEN`,且 `audit_logs` 有一条 `success=false` 记录。落点:Task 9 `test_roster_other_class_forbidden_and_audited`、`test_profile_other_class_forbidden_and_audited`。
3. **学生家庭信息等字段为 NULL 或空串** → DTO 中省略该字段(不出现 `null`),前端渲染"暂无"。落点:Task 9 `test_profile_omits_null_fields`、Task 16 `shows 暂无 placeholder when optional fields are missing`。
4. **同一用户既是 A 班班主任又是 B 班任课老师** → "我的班级"返回两个班;B 班学生档案看不到家庭信息。落点:Task 6 `test_multi_binding_field_visibility`、Task 7 `test_my_classes_multi_binding`、Task 9 `test_profile_multi_binding`、Task 13 `renders a class switcher when the teacher has two classes`。
5. **登录名前后有空格、密码含中文/emoji/组合字符、或超过 bcrypt 72 字节上限** → 登录名 trim 后有效;密码做 NFC 归一化后哈希;超长密码得到 401 而不是 500(bcrypt 5 对 > 72 字节直接抛异常)。落点:Task 4 `test_unicode_roundtrip` / `test_nfc_normalization` / `test_too_long_password`、Task 5 `test_login_trims_name` / `test_login_too_long_password_is_401`、Task 12 `submits trimmed login name and unicode password`。

    |---|---|---|
    | `POST /auth/login` | `{login_name, password}` | `{access_token, refresh_token, expires_at, user: {id, display_name}}` |
    | `POST /auth/refresh` | `{refresh_token}` | `{access_token, expires_at}` |
    | `POST /auth/logout` | `{refresh_token}` | `{ok: true}`(无需 access token) |
    | `GET /auth/me` | — | `{id, display_name, login_name}` |

- [ ] **Step 2: 实现 `layout.ts`(算法照抄)**

```ts
export interface LayoutInput { rows: number; cols: number; container: { w: number; h: number } }
export interface SeatPos { row: number; col: number; x: number; y: number }
export interface Layout { seatPositions: SeatPos[]; scale: number }

const PAD = 40
const PODIUM_H = 80

export function computeLayout({ rows, cols, container }: LayoutInput): Layout {
  const cellW = (container.w - PAD * 2) / cols
  const cellH = (container.h - PAD * 2 - PODIUM_H) / rows
  const seatPositions: SeatPos[] = []
  for (let r = 0; r < rows; r++) {
    for (let c = 0; c < cols; c++) {
      seatPositions.push({
        row: r + 1, col: c + 1,
        x: PAD + cellW * (c + 0.5),
        y: PAD + PODIUM_H + cellH * (r + 0.5),
      })
    }
  }
  return { seatPositions, scale: 1 }
}
```
