## Review Focus

以下五条是 spec 没写明、但最可能咬到真实老师的输入/失败模式,测试已落在对应 task:

```ts
type ClassPerm = 'attendance.read' | 'attendance.write' | 'review.read' | 'review.write'
  | 'seating.write' | 'board.write' | 'student.write_basic'

// GET /classes/{class_id}/students(M1 已有;每项新增 5 个字段,始终出现)
interface StudentSeat {
  enrollment_id: string; student_id: string; name: string; mk: string
  seat_row: number | null; seat_col: number | null; avatar_seed: string | null
  gender: string | null          // students.gender 原值('男'/'女'/其他/null)
  student_no: string | null
  birthdate: string | null       // 'YYYY-MM-DD'
  class_role: string | null      // 职务,如 '班长'
  seat_locked: boolean
}

// GET /students/{student_id}(M1 已有;新增 enrollment_id 必有,class_role 为空时省略)
interface StudentProfile { /* M1 字段 */ enrollment_id: string; class_role?: string }

interface Board {
  left_title: string; left_text: string; right_title: string; right_text: string
  countdown_label: string | null; countdown_date: string | null
}
// 无记录时的默认值:left_title '今日课程'、right_title '今日事项'、两段 text ''、countdown 均 null
// PUT 校验:title 1–10 字;text ≤ 120 字且 ≤ 4 行;countdown_label ≤ 12 字;二者要么都为 null 要么都有值

interface ClassroomSummary {
  today: string                  // 学校时区今天 'YYYY-MM-DD'
  timezone: string               // 'Asia/Shanghai'
  week_no: number                // 学年第几周(周一为一周开始,学年首周=1,最小 1)
  week_start: string             // 本周一
  year: { id: string; name: string; start_date: string; end_date: string }
  seat_version: number
  my_perms: ClassPerm[]          // 调用者对本班拥有的上述权限,按上表顺序
  my_subjects: string[]          // 调用者在本班的任课科目(来自 subject_teacher 绑定的 scope.subject)
  board: Board
}

type AttendanceStatus = 'leave' | 'absent' | 'late'
interface AttendanceRecord {
  enrollment_id: string; status: AttendanceStatus; reason: string | null; marked_at: string
}
interface AttendanceDay { date: string; confirmed_at: string | null; items: AttendanceRecord[] }
interface AttendanceUpdate { status: AttendanceStatus | 'present'; reason?: string | null }  // reason ≤ 100 字
interface AttendanceUpdated { enrollment_id: string; status: AttendanceStatus | 'present'; reason: string | null }
interface AttendanceMonth {
  month: string                  // 'YYYY-MM'
  items: { enrollment_id: string; date: string; status: AttendanceStatus }[]  // 按 date, enrollment_id 排序
}

interface Review {
  id: string; op_id: string; enrollment_id: string
  category: 'individual' | 'whole_class'
  reason_text: string; score_delta: number; subject: string | null
  given_at: string; given_by_me: boolean      // 不返回给出者身份(spec §2.6 默认关)
}
interface ReviewCreate {
  op_id: string                               // 客户端为"一次操作"生成的 UUID
  category: 'individual' | 'whole_class'
  enrollment_ids?: string[]                   // individual 必填 1–80 个且不重复;whole_class 必须省略
  reason_text: string                         // 1–20 字
  score_delta: number                         // -10..10 且 ≠ 0
  subject?: string | null
}
interface ReviewTotals { enrollment_id: string; total: number; week: number; plus_count: number; minus_count: number }
interface ReviewSummary { week_start: string; items: ReviewTotals[] }   // 本班每个在籍学生一项

interface SeatingSave {
  base_version: number; rows: number; cols: number           // rows / cols 1–12
  seats: { enrollment_id: string; row: number; col: number; locked: boolean }[]  // 未列出的在籍学生 = 未排座
}
interface SeatingSaved { version: number; rows: number; cols: number }

interface Todo { id: string; content: string; done: boolean; created_at: string }   // content 1–200 字

interface ReviewReason { text: string; delta: number }        // text 1–20 字;delta -10..10 且 ≠ 0
interface Preferences {
  teacher_figure: 'female' | 'male'; idle_animation: boolean
  review_reasons: ReviewReason[]                               // 1–20 条
}
```

### 错误码

| code | HTTP | 何时 |
|---|---|---|
| `NOT_FOUND` | 404 | 班级不存在;路径里的 `enrollment_id` 不是本班在籍;待办不存在或不属于本人 |
| `FORBIDDEN` | 403 | 缺权限(经 `deny()`,审计 `action`=权限点字符串、`object_type`=`class`、`object_id`=班级 id);撤销他人点评(`action`=`review.revoke`、`object_type`=`review_op`、`object_id`=op_id) |
| `NO_ACTIVE_YEAR` | 409 | 学校没有进行中的学年,且该接口需要学年(概况、考勤写、点评写) |
| `DATE_OUT_OF_RANGE` | 400 | 考勤写入/确认日期晚于学校今天,或不在当前学年 `start_date..end_date` |
| `UNKNOWN_ENROLLMENT` | 400 | `ReviewCreate.enrollment_ids` 含非本班在籍的 id |
| `NO_TARGETS` | 400 | 全班点评时没有可加分的学生(在籍且今天不是请假/缺勤) |
| `SUBJECT_REQUIRED` | 400 | 任课老师在本班教多科且未指定 `subject` |
| `SUBJECT_NOT_ALLOWED` | 400 | 指定的 `subject` 不在调用者本班任课科目中 |
| `OP_ID_CONFLICT` | 409 | `op_id` 已被其他用户使用 |
| `SEAT_VERSION_CONFLICT` | 409 | `base_version` ≠ 当前版本;`details: {current_version}` |
| `SEAT_INVALID` | 400 | `details.reason` ∈ `duplicate_position` / `out_of_grid` / `unknown_enrollment` / `duplicate_enrollment` |
| `BAD_REQUEST` | 400 | 请求体/查询参数校验失败、分页游标无效(沿用 M1 处理器) |

### 规则补充

- **考勤存储**:只存 `leave/absent/late`,"出勤"= 无记录;`PUT ... {status:'present'}` 删除该行。PUT 是**绝对赋值**(幂等),不是"轮转到下一个";轮转由前端根据最新状态计算。
- **确认考勤**:`confirm` upsert 一行 `attendance_days`(记录人与时间);`clear_exceptions=true` 时同一事务先删除当天本班全部异常(即"全部出勤")。
- **点评的科目**:调用者在本班有 `homeroom_teacher` 或 `assistant_teacher` 绑定 → 未指定 `subject` 时为 null;否则(仅任课)未指定且只教一科 → 自动取该科,多科 → `SUBJECT_REQUIRED`;指定了 → 必须属于 `my_subjects`。
- **全班点评对象**:本班在籍学生中,学校今天考勤不是 `leave/absent` 的全部学生(是否排座不限)。
- **积分统计**:`total` = 该注册记录全部未撤销点评之和;`week` = 学校时区本周一 00:00 起的未撤销点评之和;本周之星由前端取 `week > 0` 的前 3 名(同分按学号 `student_no`、再按姓名)。
- **排座保存**:`UPDATE classes SET seat_version = seat_version + 1, seat_rows = :rows, seat_cols = :cols WHERE id = :id AND seat_version = :base RETURNING seat_version` 作比较交换;0 行 → 409。成功后在同一事务内先把本班全部在籍注册记录的 `seat_row/seat_col/seat_locked` 置空/false,再写入新位置,最后插入 `seat_arrangements` 快照。
- **游标**:`next_cursor` = `base64url("{given_at ISO}|{id}")`,按 `(given_at, id)` 倒序翻页。

from app.models import Enrollment, SchoolClass, SeatArrangement

URL = f"/api/v1/classes/{CLASS_ID}/seating"


def payload(db, base=0, rows=6, cols=4, moves=None, drop=()):
    seats = []
    for i, sid in enumerate(STUDENT_IDS):
        if i in drop:
            continue
        row, col = (moves or {}).get(i, (i // 4 + 1, i % 4 + 1))
        seats.append(
            {"enrollment_id": str(enrollment_of(db, sid)), "row": row, "col": col, "locked": False}
        )
    return {"base_version": base, "rows": rows, "cols": cols, "seats": seats}


def layout_now(db):
    db.expire_all()
    rows = db.scalars(
        select(Enrollment).where(
            Enrollment.class_id == UUID(CLASS_ID), Enrollment.status == "active"
        )
    ).all()
    return {e.id: (e.seat_row, e.seat_col, e.seat_locked) for e in rows}


def version_now(db):
    db.expire_all()
    return db.get(SchoolClass, UUID(CLASS_ID)).seat_version

- Produces:
  - `export interface DraftStudent { enrollmentId: string; name: string; gender: 'female' | 'male' | null; row: number | null; col: number | null; locked: boolean }`、`export interface Cell { row: number; col: number }`(`draft.ts`)
  - `algorithms.ts`(均返回新数组,不改入参;锁定学生原位不动,其占用的格子不参与分配;放不下的学生 `row/col = null`):
    - `shuffleSeats(students: DraftStudent[], rows: number, cols: number, rand: () => number): DraftStudent[]`:未锁定学生 Fisher–Yates 打乱后按行优先填入空闲格
    - `genderPairSeats(students, rows, cols, rand): DraftStudent[]`,算法:

```text
1. 空闲格 = 全部格子 − 锁定学生的格子。
2. 同桌位 = 每排第 (2p+1, 2p+2) 列两格都空闲的组合;单人位 = 其余空闲格(含奇数列最后一列)。
3. 未锁定学生按性别分为男 / 女 / 未知,各自打乱。
4. 男女各取一人组成同桌,直到一方用完;剩余学生(含未知)打乱后两两成对,落单者为单人。
5. 打乱"成对"列表的顺序,依次放入同桌位(同桌位不够时,多出的对拆成两个单人)。
6. 单人依次放入单人位,不够再放进剩下的同桌位空格(行优先)。
7. 仍放不下的学生进入托盘。
```

  - `draft.ts`:
    - `export interface SeatDraft { rows: number; cols: number; baseVersion: number; students: DraftStudent[]; past: Pick<SeatDraft, 'rows' | 'cols' | 'students'>[]; selected: string | null }`
