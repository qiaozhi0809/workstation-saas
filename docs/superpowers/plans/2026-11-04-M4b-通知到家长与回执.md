**Goal:** 通知可以发给家长:班主任给本班家长发班级公告,管理者给全校 / 年级 / 班级家长发;发送人可以要求"已知晓"或单选回执(可留言、可设截止),家长和老师都能回执,发送人看按学生汇总的回执统计并导出;家长端加"通知"页签,实时到达;顺带修 L44、L46、L47(通知与账号列表)、L49。

## Global Constraints

- 沿用 M4a 计划的 Global Constraints(家长端手机优先、家长看不到别的孩子、学校时区、提交身份、仓库公开、本地降载)。
- 迁移 `revision = "0010"`、`down_revision = "0009"`(复核时以 M4a 合并后的最后一条为准)。
- 回执文字:选项 1–20 字、2–5 个、互不相同;留言 ≤ 200 字;截止时间必须晚于发送时刻。
- 家长对象的收件人只含**主家长**;次要家长、只读 / 已结束的绑定、`notify_enabled = false`、账号非 `active` 都不收。
- CSV 导出用 `fetch` 带 `Authorization` 头取回(UTF-8 BOM),写审计。
- 新增查询键:`['notices', 'options']`、`['notices', id, 'acks']`、`['class-notices', classId, page]`;家长端收件箱沿用 `['notices', 'inbox']`。
- 新增审计动作:`notice.ack`、`notice.ack_export`;`notice.send` 的 `extra` 增加 `audience` 与 `ack`。

## Review Focus

1. **一个家长两个孩子都在收件范围里**:只收一条通知、只回执一次,两个孩子在统计里都算已回,收件箱写明涉及哪两个孩子。落点:Task 2 `test_two_children_one_notice`。
2. **该收的人收不到 / 不该收的人收到了**:次要家长、毕业只读家长、没有绑定家长的学生 → 不在收件人里,发送人看到"N 名学生还没有绑定家长"。落点:Task 2 `test_parent_recipients_primary_active_only`。
3. **截止后、撤回后还能回执 / 回执改了又改**:截止或撤回后 409,截止前再交一次覆盖上一次。落点:Task 2 `test_ack_rules`。
4. **越权发给家长**:年级组长发全校或别的年级家长、班主任发别的班家长、任课老师发班级公告 → 403 + 拒绝审计。落点:Task 2 `test_grade_head_parent_scope`、Task 3 `test_class_notice_scope`。
5. **选好的人在发送前被冻结或解绑(L46)**:返回 409 并列出是谁,前端在选人框里标出"已不可选"并允许去掉后重发。落点:Task 2 `test_unavailable_recipient_409`、Task 5 `marks unavailable recipients`。

## HTTP 契约(冻结)

> 路径前缀 `/api/v1`。M3b 的通知契约照旧,下面只写新增与修改。

```ts
type AckSpec =
  | { kind: 'none' }
  | { kind: 'confirm' }                                          // 只点"已知晓"
  | { kind: 'choice'; options: string[]; allow_note: boolean }   // 2..5 个选项
type Audience = 'teachers' | 'parents'

// 修改:M3b NoticeInput 追加三个可选字段
interface NoticeInput {
  title: string; content: string; target: NoticeTarget
  audience?: Audience          // 默认 'teachers'
  ack?: AckSpec                // 默认 {kind:'none'}
  ack_deadline?: string | null // ISO 时间,须晚于现在
}
// 修改:M3b NoticeSent 追加
interface NoticeSent { /* 已有字段 */ audience: Audience; ack: AckSpec; ack_deadline: string | null; acked: number; students_without_parent: number }
// 修改:M3b InboxItem 追加
interface InboxItem {
  /* 已有字段 */
  ack: AckSpec; ack_deadline: string | null
  my_ack: { choice: number | null; note: string | null; acked_at: string } | null
  students: string[]           // 家长收到的:这条通知涉及的自己孩子的姓名;老师收到的为 []
  can_ack: boolean             // 需要回执、未撤回、未截止、且(家长)至少一个涉及的孩子绑定仍在用
}
interface NoticeOptions { school_wide: boolean; grades: { id: string; name: string }[]; classes: { id: string; name: string; grade_id: string }[] }   // L44
interface AckInput { choice: number | null; note: string | null }
interface AckRow {
  user_id: string; user_name: string
  student_id: string | null; student_name: string | null; class_name: string | null   // 家长对象按学生一行;老师对象为 null
  read_at: string | null; choice: number | null; note: string | null; acked_at: string | null
}
interface AckStats { audience: Audience; ack: AckSpec; ack_deadline: string | null; total: number; read: number; acked: number; counts: number[]; students_without_parent: number; rows: AckRow[] }   // counts:choice 时每个选项的行数,否则 []
interface ClassNoticeInput { title: string; content: string; ack?: AckSpec; ack_deadline?: string | null }
```

|---|---|---|---|---|---|
| POST | `/admin/notices` | `notice.send` | `NoticeInput` | 201 `NoticeSent` | **改**:`audience='parents'` 时 `target` 只能是 `school` / `grade` / `class`(`users` → 400 `TARGET_INVALID`);作用域判定同老师对象;`target_label` 为"全校家长 / 三年级家长 / 三年二班家长" |

| GET | `/accounts?page=` | 同 M3a | — | — | **改(L47)**:`page` 1..1000,`q` ≤ 50 字 |

**家长对象的收件人**(发送那一刻确定,写 `notice_recipients` 与 `notice_students`):
- 范围内的学生 = 当前学年在读班(`classes.active`)里 `status='active'` 的注册对应的学生(班级 / 年级 / 全校)。
- 每个学生取主家长:`parent_links.is_primary`、`status='active'`、`notify_enabled`,且账号 `active`;没有就计入 `students_without_parent`,不写 `notice_students`。
- 收件人 = 这些主家长去重(不含发送人自己);`notice_students` 每个学生一行(`parent_user_id` = 他的主家长)。
- 收件人为空 → 400 `NO_RECIPIENTS`(同 M3b)。

**回执规则**(`POST /notices/{id}/ack`):
- 不是收件人 → 404;`ack.kind = 'none'` → 409 `ACK_NOT_REQUIRED`;已撤回 → 409 `NOTICE_RECALLED`;过了 `ack_deadline` → 409 `ACK_CLOSED`。
- 家长:这条通知涉及的自己孩子的绑定**全部**不再是在用(只读或结束)→ 403 `ACK_NOT_ALLOWED`。
- `confirm`:`choice` 与 `note` 必须为 null;`choice`:`0 ≤ choice < len(options)`,`note` 只在 `allow_note` 时可非空(≤ 200 字,去首尾空格,空串视为 null)。不合规 → 400 `ACK_INVALID`。
- 再次回执覆盖 `ack_choice`、`ack_content`、`acked_at`;回执同时把 `read_at` 补上(若为空)。

**指定的人失效(L46)**:`users` 目标里,本校账号但已非 `active`、或已没有任何当前学年教师绑定 / 在任管理岗的 → 409 `RECIPIENT_UNAVAILABLE`,`details = {user_ids: [...]}`,message"有 N 位已不能接收通知,请去掉后重发";账号在用且有绑定、只是不在发送人范围内的,照旧 403(M3b `test_grade_head_limits` 保持通过);不是本校账号的照旧 403。
