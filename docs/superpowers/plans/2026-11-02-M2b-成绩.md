## HTTP 契约(冻结)

> 后端段(Task 1–5)按此实现,前端段(Task 6–20)按此编写类型与 mock。**任何改动必须先改本节并通知其他段。** 全部路径前缀 `/api/v1`,错误外壳沿用 M1:`{"error": {"code", "message", "details"?}}`。下面用 TypeScript 记法描述 JSON;后端 pydantic 模型字段名与之逐一相同。

### 类型

```ts
type ClassPerm = /* 现有 7 个 */
  | 'exam.read' | 'exam.write' | 'score.write' | 'score.export' | 'student.manage' | 'student.export'

type ExamType = '月考' | '期中' | '期末' | '周测' | '单元测' | '模拟考' | '其他'
interface SubjectFull { name: string; full: number }   // name 去首尾空格后 1–10 字;full 为 1–1000 的整数

// GET /classes/{id}/subjects:本班常用科目;班级还没有列表时按年级名推断学段返回预设(不落库)
// 学段:年级名含"高" → 高中;含"初"或"七/八/九" → 初中;含"一/二/三/四/五/六"且含"年级" → 小学;其余 → 初中
// 预设(照原版):小学 语文/数学/英语/科学/道法 各 100;
//   初中 语文/数学/英语 120,物理/化学/道法/历史/地理/生物 100;高中 语文/数学/英语 150,物理/化学/生物/政治/历史/地理 100

interface Exam {
  id: string; name: string; exam_type: ExamType; date: string     // 'YYYY-MM-DD'
  subjects: SubjectFull[]                                          // 调用者可见的科目,保持考试里的顺序
  created_by_me: boolean
  progress: { entered: number; total: number }
  // total = 本班在籍人数;entered = 可见科目每科都有记录(分数或缺考)的在籍人数
}
interface ExamInput { name: string; exam_type: ExamType; date: string; subjects: SubjectFull[] }
// name 去首尾空格后 1–30 字;subjects 1–20 项、名称不重复;date 不校验范围(可补录往年考试)

type ScoreValue = number | null                                    // null = 缺考
interface ScoreSheet {
  exam: Exam
  items: { enrollment_id: string; scores: Record<string, ScoreValue> }[]
  // 本班每个在籍学生一项(没录过的 scores 为 {});scores 只含可见科目里已有记录的科目
}
interface ScoreCell { enrollment_id: string; subject: string; value: number | 'absent' | null }  // null = 清空(删除记录)
interface GradebookExam extends Exam {
  scores: Record<string, Record<string, ScoreValue>>               // enrollment_id → 科目 → 分数;只含在籍学生、可见科目
}
interface Gradebook { exams: GradebookExam[] }                     // 旧→新(date, created_at 升序)

interface Contact { name: string; relation: string; phone: string; job: string }
// name ≤ 20、relation ≤ 10、phone ≤ 20、job ≤ 20(均去首尾空格,可为空串);name 与 phone 不能同时为空

// GET /classes/{id}/students/records 与导出:StudentSeat 的全部字段 + 按权限出现的字段
interface StudentRecord extends StudentSeat {
  boarding?: boolean                                   // student.read_basic
  family_structure?: string | null; family_note?: string | null; contacts?: Contact[]   // student.read_family
  learning_summary?: string | null                     // student.read_learning
  personality?: string | null; health_notes?: string | null; tags?: string[]; note?: string | null  // student.read_profile
}
// 与档案接口不同:有权限的字段总是出现(值可为 null / [] / false),没权限的字段不出现

// GET /students/{id}(已有)新增可选字段,规则同 M1(无权限 / 空值省略):
interface StudentProfile { /* 现有字段 */
  boarding?: boolean; family_note?: string; contacts?: Contact[]; note?: string
  teacher_notes?: TeacherNote                          // 只返回调用者本人那条;原先是任意 JSON,现在固定为此形状
}
interface TeacherNote { text: string; updated_at: string }

interface StudentInput {
  name: string                                         // 去首尾空格后 1–20 字
  gender: '男' | '女' | null
  student_no: string | null                            // ≤ 20 字;空串按 null
  birthdate: string | null
  class_role: string | null                            // 1–10 字或 null(同 M2a)
  tags: string[]                                       // ≤ 12 个,每个 1–10 字,去重
  boarding: boolean
  family_structure: string | null                      // ≤ 10 字
  family_note: string | null; learning_summary: string | null; personality: string | null; note: string | null  // 各 ≤ 500
  health_notes: string | null                          // ≤ 300
  contacts: Contact[]                                  // ≤ 2
  seat: { row: number; col: number } | null            // 添加 / 编辑时有效;null = 不排座(编辑时 = 移出座位)
}
interface StudentImport { rows: Omit<StudentInput, 'seat'>[]; auto_seat: boolean }      // rows 1–200
interface StudentImported { created: number; skipped: { index: number; reason: 'duplicate' | 'student_no_taken' }[] }
```

### 错误码(新增;M2a 的照旧)

| code | HTTP | 何时 |
|---|---|---|
| `NOT_FOUND` | 404 | 考试不属于本班;任课老师访问不含本科目的考试;`enrollment_id` 不是本班在籍 |
| `FORBIDDEN` | 403 | 缺权限(`object_type`=`class`);任课老师改 / 删别人建的考试;任课老师删除含有他不可写科目的考试,即使是创建者(均 `action`=`exam.write`、`object_type`=`exam`、`object_id`=考试 id,不删任何东西)(后一种为 2026-11-02 契约补充,协调会话批准,段 A 实现) |
| `NO_ACTIVE_YEAR` | 409 | 建考试、添加 / 导入学生时学校没有进行中的学年 |
| `SUBJECT_NOT_ALLOWED` | 400 | 任课老师建 / 改的考试含非本科目;写入的格子科目不可写;`details: {subject}` |
| `UNKNOWN_SUBJECT` | 400 | 写入的格子科目不在考试里;`details: {subject}` |
| `UNKNOWN_ENROLLMENT` | 400 | 写入的格子 `enrollment_id` 不是本班在籍 |
| `SCORE_INVALID` | 400 | 分数 < 0、> 满分或多于 1 位小数;`details: {enrollment_id, subject}` |
| `FULL_BELOW_SCORES` | 400 | 改考试时某科满分低于该科已录的最高分;`details: {subject}` |
| `DUPLICATE_STUDENT_NO` | 409 | 添加 / 编辑学生的学号与本班另一位在籍学生相同 |
| `SEAT_INVALID` | 400 | `seat` 超出本班行列(`details.reason`=`out_of_grid`,沿用 M2a) |

| `BAD_REQUEST` | 400 | 请求体校验失败(沿用 M1 处理器) |

### 规则补充

- **写分数**:整批校验通过才写(任一格出错整批 400,不写任何格);同一请求里同一格出现多次以最后一次为准;`value=null` 删除记录、`'absent'` 存缺考、数字 upsert(`ON CONFLICT (exam_id, enrollment_id, subject)`);后写覆盖先写。每次请求记一条审计 `score.write`(`object_type`=`exam`,`extra: {cells: n}`)。
- **改考试**:去掉的科目连同其分数一并删除;科目满分改低于已录最高分 → `FULL_BELOW_SCORES`;请求里的新科目(名称不在本班列表)追加到 `classes.subjects` 末尾;班级还没有列表时先用预设初始化再追加。建考试同样写回。
- **任课老师改考试**(2026-11-02 契约补充,协调会话批准,段 A 实现):任课老师 PUT 考试只作用于他可写的科目,看不到的科目和分数原样保留在原位置;班主任 PUT 仍是整体替换(含科目顺序)。
- **删考试**:连同分数删除;审计 `exam.delete`。
- **座位(添加 / 编辑)**:目标格有别人 → 该同学被固定则 `SEAT_LOCKED`;否则该同学搬到本学生原来的座位(交换),本学生原来没座位时搬到按"排、列"顺序第一个空座(都满则变为未排座)。任何座位变动都让 `classes.seat_version + 1`,本学生的 `seat_locked` 置 false。
- **删除学生**:注册记录 `status='removed'`、`left_at=now`、座位清空、`seat_version + 1`;学生档案与历史事件不删。所有"在籍"查询(`status='active'`)自然排除。审计 `student.remove`。
- **导入去重**:逐行与本班在籍学生 **以及本批已接受的行** 比较:同名且(学号相同或本行学号为空)→ `duplicate`;学号已被不同名的人占用 → `student_no_taken`。`auto_seat=true` 时被接受的行按顺序放进"排、列"顺序的空座,放满为止。审计 `student.import`(`extra: {created, skipped}`)。
- **新学生编号**:`students.mk` 由服务端生成 `"S" + secrets.token_hex(4).upper()`,冲突重试。
