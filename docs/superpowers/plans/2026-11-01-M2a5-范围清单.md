# M2a.5 UI 基础与打磨 · 范围清单

> 插在 M2a(教室交互)与 M2b(成绩)之间。目的:现在页面还少,先把 UI 地基打好,M2b 之后新增的大量页面直接用同一套令牌和组件。
> 实施计划见 [`2026-11-01-M2a5-UI基础与打磨.md`](2026-11-01-M2a5-UI基础与打磨.md)。**只改 UI,不改行为和接口。**

## 用户拍板

1. **主题切换到 shadcn/ui**(2026-11-01):采用 shadcn 默认的 new-york 风格、neutral 中性灰基色,不另做品牌色。

## 计划采用的默认值(用户 2026-11-02 确认按默认值执行)

| 项 | 默认值 |
|---|---|
| 深色模式 | 浅色 / 深色 / 跟随系统三档,默认跟随系统,顶栏一键切换,记在本机 |
| 状态色 | 新增 success / warning / info;考勤 出勤绿、请假琥珀、缺勤红、迟到蓝;加分绿、扣分红;浅深两套对比度都过 WCAG AA |
| 密度 | shadcn 默认;教室工具栏用小号 |
| 教室画面 | SVG 场景不改;深色模式下画面保持浅色,周围界面变深 |
| 响应式 | 教师端桌面 / 一体机为主、平板可用;手机宽度不横向溢出(为 M4 家长端打底) |
| 图标 | lucide |

## 逐屏清单

| 屏幕 / 部件 | 处理 |
|---|---|
| 登录页 | 卡片布局、品牌图标、登录中状态、主题按钮 |
| 教师外壳(顶栏) | 新的 `AppShell`:窄屏收进菜单抽屉;跳到主要内容链接;主题按钮 |
| 教室页框架 | 加载 / 出错(可重试)/ 无班级状态;舞台外框;工具栏图标按钮;模式条支持方向键 |
| 日常 / 考勤 / 点评 / 排座四个模式 + 随机点名 | 考勤条、点名卡、点评弹层、积分榜、排座条、待安排托盘全部换令牌和组件;积分榜、冲突对话框改为标准对话框(投屏时可见) |
| 右侧概况栏 | 卡片化、状态色;1100px 以下改为浮层 |
| 悬停卡 | 跟随主题 |
| 黑板编辑 | 标准对话框,点外面不会误关;手机上单列 |
| 学生档案抽屉 | 标准侧边抽屉(带焦点陷阱,解决 M2a 遗留项)、加载失败可重试、后续标签显示"暂未开放" |
| 我的偏好 | 分组卡片 |
| 提示条(Toast) | 跟随主题 |
| 404 / 管理端 / 家长端占位 | 统一的空状态 |

## 不做

教室 SVG 的深色画面;截图基线测试;自动无障碍扫描工具;管理端 / 家长端页面本身(M3 / M4)。
