# M2a 教室交互 · 范围清单

> 本文件逐项记录原版教室页(PRD `reference-html/features-extracted.md` §2、§5、§13)在新项目里的处理方式。
> 实施计划见 [`2026-11-01-M2a-教室交互.md`](2026-11-01-M2a-教室交互.md)。

## 用户拍板的四条总原则

1. **画面完整还原,但不照搬原版**:教室场景的组成(课桌、学生、讲台和老师、前墙黑板、两侧陈设区)全部保留;角色造型、家具画法、配色、动画和 UI **由新项目重新设计**,不复用原版的形状、配色和动画参数(与 spec D05 一致)。
2. **排座 = 本地草稿 + 一次保存**,带版本号,两人同时改时后保存的人收到冲突提示。
3. **任课老师对考勤只读**(spec §2.3 只授予任课老师"本科目成绩与点评")。
4. **不精简**:凡是不依赖成绩数据(M2b)或 AI(M2c)的条目都放进 M2a;原先建议"延后"的老师偏好、学生职务、固定座位一并纳入。

## 逐项清单

标记:**对标** = 行为与原版一致(画面自绘);**改** = 行为按 B 端需要调整;**新增** = 原版没有;**后移** = 依赖后续里程碑的数据,在该里程碑实现;**删除** = spec §4.6 已决定不做。

### A. 教室画面(ClassroomMap 重写)

| # | 原版功能 | 处理 | 说明 |
|---|---|---|---|
| A1 | 课桌、学生背影、讲台和老师、前墙(黑板/智慧屏/本周之星/本月寿星/挂钟) | 对标(自绘) | 新造型:圆头"豆豆人"、小组色卫衣;女生/男生各 3 种发型由 `avatar_seed` 哈希决定 |

## 写入权限

| 操作 | 班主任 | 副班主任 | 任课老师 | 校领导 |
|---|---|---|---|---|
| 看考勤 | ✓ | ✓ | ✓ | ✓ |
| 记考勤 | ✓ | ✓ | — | — |
| 看点评 | ✓ | ✓ | ✓ | ✓ |
| 写点评 | ✓ | ✓ | ✓(自动记本科目) | — |
| 撤销点评 | 仅自己给的 | 仅自己给的 | 仅自己给的 | — |
| 排座 / 行列数 / 黑板 / 学生职务 | ✓ | — | — | — |

老师之间不返回"这条点评是谁给的",只返回"是否我给的"(对应 spec §2.6"教师可见互相的点评频率"默认关)。家长端对考勤和点评的可见性在 M4 与"家长收到负向点评"开关一起定。
