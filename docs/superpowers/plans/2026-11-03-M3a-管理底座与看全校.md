### 认证与身份

```ts
type Context = 'teacher' | 'admin'
type AdminPerm =
  | 'school.view'        // 计算得出:有校长 / 主任 / 年级组长任一身份(能看业务数据)
  | 'org.manage' | 'account.manage' | 'settings.manage' | 'audit.read'
  | 'ai.usage' | 'notice.send' | 'exam.grade_write' | 'year.upgrade'

interface UserBrief {                 // POST /auth/login 的 user;GET /auth/me 另加 login_name
  id: string; display_name: string
  contexts: Context[]                 // 顺序固定:teacher 在前
  admin_perms: AdminPerm[]            // 按上面联合类型的顺序
  must_change_password: boolean
}
interface ChangePassword { old_password: string; new_password: string; refresh_token: string }
```

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/auth/login` | 响应 `user` 换成 `UserBrief`(多 3 个字段) |
| GET | `/auth/me` | `UserBrief & { login_name: string }`;`must_change_password = true` 时也可调用 |
| POST | `/auth/password` | `ChangePassword` → 200 `{ok: true}`;旧密码错 400 `WRONG_PASSWORD`;新密码不合规 400 `PASSWORD_WEAK`(`details.reason ∈ too_short / too_long / one_kind / same_as_old`,`too_long` = 超过 72 字节);成功后清 `must_change_password`,作废该用户除 `refresh_token` 外的全部刷新令牌;写审计 `account.password_change`。**补充 6**:旧密码连续错误与登录失败共用计数,超限 429 `ACCOUNT_LOCKED`,改密码成功后清零。`must_change_password = true` 时也可调用 |

- `must_change_password = true` 的用户调用**其他任何**需要登录的端点:403 `PASSWORD_CHANGE_REQUIRED`(`/auth/me`、`/auth/password`、`/auth/logout`、`/auth/refresh` 除外)。
- 密码规则:长度 ≥ 8 且 ≤ 72 字节(UTF-8,沿用 M1 的上限);字母、数字、其他字符三类里至少两类;不能与旧密码相同。

**任职规则**

1. `identity = 'subject'` 时 `subject` 必填(1..10 字),其他身份必须为 null,否则 400 `BAD_REQUEST`。
2. `user_id` 必须是本校 `active` 账号且有 `teachers` 行,否则 400 `BAD_REQUEST`(`details.field = 'user_id'`)。
3. 写入:`teacher_assignments`(`identity`、`subject`、`academic_year_id` = 当前学年、`started_at = now`)+ `role_bindings`(`homeroom → homeroom_teacher`、`assistant → assistant_teacher`、`subject → subject_teacher`;`scope = {class_id}`,任课再加 `subject`;`academic_year_id` = 当前学年)。
4. `homeroom`:该班已有在任班主任时,先结束旧的任职与绑定,并把 `classes.homeroom_teacher_id` 改成新老师的 `teachers.id`。
5. 同一人同一班同一身份(任课再加同一科目)已在任:409 `ALREADY_ASSIGNED`。
6. 结束任职:`teacher_assignments.ended_at = now`,对应 `role_bindings.ended_at = now`(按 user、role、`scope.class_id`、`scope.subject` 匹配在任的那条);结束的是班主任时 `homeroom_teacher_id = null`。
7. 管理岗:`principal / dean / it_admin` 的绑定 `scope = {school_id}`、`academic_year_id = null`(跨学年,学年升级不复制也不结束);`grade_head` 的绑定 `scope = {grade_id}`、`academic_year_id` = 当前学年(由 M3b 的升级向导逐个指定新学年的组长)。

```ts
    classes: { class_id: string; class_name: string; plus: number; minus: number; net: number }[]     // 净分倒序
    bottom: { class_id: string; class_name: string; student_id: string; name: string; net: number }[]  // 净分最低 5 人,净分 < 0 才列
    teachers: { user_id: string; display_name: string; count: number }[]                            // 次数倒序
  }
}
interface BoardClass {
  id: string; name: string; room: string; homeroom_name: string | null
  seat_rows: number; seat_cols: number; desk_size: 1 | 2 | 3; podium_left: number; podium_right: number
  seats: StudentSeat[]                               // 与 GET /classes/{id}/students 的元素同形
  attendance: Record<string, AttendanceStatus>       // enrollment_id → 今日非出勤状态
  metrics: { students: number; present: number; leave: number; absent: number; late: number; confirmed: boolean; week_net: number }
}
interface BoardView { grades: { id: string; name: string }[]; grade_id: string | null; classes: BoardClass[] }
```

| 方法 | 路径 | 请求 | 响应 | 说明 |
|---|---|---|---|---|
| GET | `/admin/today` | — | `TodayView` | 只算调用者能 `class.read` 的当前学年在读班;没有 `school.view` 403 |
| GET | `/admin/board?grade_id=` | — | `BoardView` | `grades` 只列调用者可见的年级;`grade_id` 省略时取第一个;传了不可见的年级 403;没有 `school.view` 403 |
| GET | `/admin/board/classes/{class_id}` | — | `BoardClass & { absentees: { student_id: string; name: string; status: 'leave' \| 'absent'; reason: string \| null }[] }` | 单班只读页用;权限 `school.view` 加可见范围;班级不可见**或不存在一律 403 并记失败审计,没有 404**(不泄露班级是否存在) |

- "今日" = 学校时区的今天(`school_today`);"本周" = 本周一 00:00 起(`week_monday` + `local_day_start_utc`);点评只算未撤销的(`revoked_at IS NULL`)。
- `present` = 在读人数 − 请假 − 缺勤(迟到算出勤,与教室出勤小牌一致)。
- 单班只读页用上面的 `GET /admin/board/classes/{class_id}` 取班名、教室、座位布局、今日考勤与缺勤原因(`ClassroomSummary` 不带班名与布局,`classesApi.mine` 只返本人班,`/admin/classes/{id}` 要 `org.manage`,领导无法复用);学生档案抽屉复用 `GET /students/{id}`(领导身份已有读权限)。
